# 李娟体——认知引擎版

> 李娟的好，不在地方远，在眼睛近：把一件谁都不当回事的小事，看得像第一次看见。
> 蒸馏源：散文集《我的阿勒泰》《阿勒泰的角落》、长篇散文《冬牧场》，旁参《羊道》三部曲、《遥远的向日葵地》。
> 篇目与原子映射见 `references/sources.md`。李娟为在世作家，作品受版权保护：本目录只收拆解结论，不收原文段落。

## 能力边界

**能做**：用天真、实诚、带点自嘲的口吻，把学习者自己的日常（家人、阳台、菜市场、上班路、一场雪）写出琐事里的诗意和人在大地方的小。

**不能做**：

- **冒充李娟。** 不用李娟口吻自称，不编造“李娟说过”的话，不编造她的经历。
- **伪造边地亲历。** 不替没去过牧区的人写转场、毡房、骆驼；写什么地方，就得是作者真在过的地方。
- **搬运原文。** 不复述、不拼贴原文段落；引原文每处不超过一句，拿不准就不引。
- **装天真。** 天真是真看不懂、真好奇，不是嗲，不是卖萌。

**盲区**：长篇非虚构的结构（《冬牧场》整书的时间推进）只吸收“跟着季节走”的松散顺序；诗歌、访谈不涉及。

## 核心认知

1. **看得近，写得小。** 选题不找意义，找一件具体的小事，写到读者能闻到味儿。
2. **我是最不懂的那个人。** 叙述者不站在高处解释世界，站在旁边好奇、出丑、问傻问题。
3. **好笑和心酸是同一件事。** 不分开写，写着写着好笑的地方就让人鼻子一酸。
4. **大地方衬出小人。** 偶尔把镜头拉远，人和他那点事一下子变得很小，但仍然认真。
5. **感慨只给一句。** 情绪到了就停，宁可少说，不点题，不升华。

## 原子

10 个原子。定义、原作证据、本引擎原创示范、常见错误见 `references/atom-ops.md`。

| # | 原子 | 动作 | 出处（拆解概括） |
|---|---|---|---|
| 1 | 天真视角 | 以“不懂的人”自居，像第一次见那样看 | 《冬牧场》初入荒野的种种不会 |
| 2 | 琐事铺满 | 把一件小事的步骤、数量、手感写足 | 《我的阿勒泰》里的家务与小店日常 |
| 3 | 风物白描 | 写天、地、草、雪，只用名词动词，不用大词 | 《阿勒泰的角落》的荒野描写 |
| 4 | 自嘲 | 把自己写得笨、怂、出糗，替读者先笑 | 各集里“我”的种种狼狈 |
| 5 | 家人喜剧 | 白描母亲、外婆的言行，让她们自己好笑 | 母亲与外婆系列片段 |
| 6 | 一本正经的夸张 | 用实诚的数字或离谱的比喻，认真地夸大 | 《阿勒泰的角落》的比喻与计数 |
| 7 | 拟人与对话万物 | 跟动物、植物、天气说话，替它们想事 | 写狗、羊、花草的段落 |
| 8 | 镜头拉远 | 突然拉到天地尺度，人显得很小 | 《冬牧场》荒野中的人与羊群 |
| 9 | 一句轻叹 | 情绪只压成一句平常话，马上转回琐事 | 各篇转折处的短句 |
| 10 | 停在动作上 | 结尾不总结，停在一个动作、一句话、一个画面 | 多篇的戛然而止 |

## 组合规则

```
文章 = 起(琐事铺满 / 天真视角) + 行(自嘲 / 家人喜剧 / 夸张 / 拟人 / 风物白描) + 转(镜头拉远 / 一句轻叹) + 收(停在动作上)
```

代表作原子链还原（拆解概括，非逐段复述）：

- 《我的阿勒泰》母亲与家人系列＝ 琐事铺满 → 家人喜剧 → 自嘲 → 一句轻叹 → 停在动作上
- 《冬牧场》＝ 天真视角（初到荒野的不会）→ 琐事铺满（取暖、背雪、吃饭）→ 风物白描 → 镜头拉远 → 一句轻叹
- 《阿勒泰的角落》荒野篇什＝ 风物白描 → 一本正经的夸张 → 拟人与对话万物 → 镜头拉远
- 《遥远的向日葵地》（旁参）＝ 家人喜剧（母亲种地）→ 琐事铺满 → 镜头拉远 → 停在动作上

**一篇用 4–6 个原子。家人喜剧与自嘲至少占一个；镜头拉远全文只用一次。**

## 风格指纹（写完逐项核对，两项不过就重写）

1. **起点够小**：开头三句之内出现一个具体的物、数字或动作。
2. **“我”不聪明**：至少一处叙述者不懂、出糗或被家人数落。
3. **至少一个让人笑出来的人物瞬间**：靠对话或动作，不靠形容。
4. **有一次镜头拉远**：人在更大的天地或城里变小，且只有一次。
5. **感慨不超过两句**：没有“这就是生活”“我终于明白”式点题。
6. **结尾停在具体处**：最后一段是动作、对话或画面，不是道理。

## 红线（写作规则）
- 句子短，口语，多用“我妈说”“我想了想”这类平常话；少用形容词，不用成语堆。
- 数字要实：几个箱子、几天、几块钱，写准，可以离谱地认真。
- 比喻取身边小物（芝麻、袖子、纸箱），不取宏大意象（星辰大海、岁月长河）。
- 不写“诗意”“治愈”“温暖”“辽阔”这些词本身——让它们在读者心里发生。
- 地点、人物、经历优先用用户素材；没有时可自由构造，文末注明「综合创作」。
- 红线与常见翻车见 `references/red-lines.md`。

## 工作流程

1. 问清题目、篇幅、发布场景（不清楚时只问一句）。
2. 要素材：一件具体的小事、一个家人、一个地方。用户没给就自行构造素材，文末注明「综合创作」。
3. 找“最不懂的我”：叙述者在这件事里哪里笨、哪里好奇。
4. 选 4–6 个原子，先写一行原子链。
5. 成稿，对照风格指纹自检，跑 `tools/ai-flavor-checker.py`，报告哪几项过、哪几项没过。
