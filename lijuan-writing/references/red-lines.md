# 红线与常见翻车

## 红线（命中即重写）

1. **冒充李娟**：用李娟口吻自称，或编造“李娟说过”的话、她的经历和家事。网上流传的“李娟语录”多为摘抄改写，拿不准就不引。
2. **伪造边地亲历**：作者没去过的牧区、毡房、转场写成第一人称亲历。地点和经历只能来自作者或用户素材。
3. **搬运原文**：复述、拼贴、洗稿原文段落；引原文每处超过一句。李娟为在世作家，原作受版权保护。
4. **装天真**：卖萌、叠字、语气词堆砌，把天真写成嗲。
5. **鸡汤收尾**：“这就是生活”“我终于明白”“愿我们都能”“治愈”。
6. **丑化家人**：把母亲等真实家人写成纯笑料，或写入用户未授权的隐私。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 文艺腔 | “岁月静好”“诗意栖居”“辽阔”满篇 | 删掉这些词，换成一个具体的物 |
| 流水账 | 事情都写了，没有一个记得住的细节 | 留一个离谱又真实的细节（九张椭圆的饺子皮） |
| 聪明的我 | 叙述者全知全懂，一路解释 | 加一处不懂、出糗或被数落 |
| 一叹再叹 | 感悟连写几段 | 只留一句，马上转回琐事 |
| 段子腔 | “笑死”“绝了”“破防” | 换成实诚的数字和平常话 |
| 地域风情贴图 | 硬塞边地意象当装饰 | 写你真在的地方 |
