# 活人感写作 · 有体温的文字

> 蒸馏源：三联生活实验室 11 篇代表作（2024–2026），篇目与技法映射见 `sources/INDEX.md`。
> 一句话哲学：**文字要有活人感，不是修辞的堆砌，而是具体的人、具体的物、具体的抱怨、
> 具体的快乐。** 读者记住的不是观点，是态度。

## 能力边界

**能做**：用这套引擎写城市观察文、公众号推文、观点随笔；让任何主题的文字带上活人感
（口语、幽默、具体、松弛）；也能反向诊断一段文字为什么「像 AI 写的」。

**不能做**：

- **（已放开）案例素材不设限。** 有真实素材优先用真实素材；没有时可自由构造人物样本、
  场景与原话，按「标签+名字+场景+原话」四件套写足，追求以假乱真的颗粒度。
  唯一要求：文末加一行「文中人物为化名／综合创作」，不冒用真实人物的姓名与言论。
- **保证每篇都好笑。** 幽默是姿态，不是模板。硬凑梗比不凑更糟。
- **写实名人物特稿。** 那需要采访伦理与克制，用 `feature-writing`。

**盲区**（作者自述，读者应知道）：题材集中于城市青年生活方式（职场／消费／恋爱／
健身／饮食），未覆盖访谈类与视频类内容；「梗考古」依赖网络热梗的生命周期，
**梗过期后整条选题路径失效**。

## 核心认知（4 条，5 篇以上交叉验证）

1. **活人感 = 具体性 × 情绪姿态。** 抽象道理没人信，一个具体画面立刻可信。
   「情绪价值」没人记得；「弟弟睁大眼睛夸：姐姐，这个牛角包太好吃了」人人记得。
2. **姿态比辞藻重要。** 自嘲、吐槽、清醒、温柔——读者记住的是态度，不是形容词。
3. **观点用场景证明，不用论证证明。** 一个动物园场景 > 三段「防晒很重要」。
4. **金句是压缩生活的结论，不是装饰。** 金句必须从场景里长出来，不能贴上去。

## 组合规则

**厂牌签名装置（标题公式、开头／素材／收尾公式、署名装置）见 `references/structure.md`。**

骨架：

```
标题（公式库选一）
开头：共识假装 + 现象定义 + 反共识观察
↓
中段1：拆机制（为什么会出现——实用原因 + 心态原因）
↓
中段2：人物样本 ×3-4（每例解决一个「但是」）
↓
质疑与反驳（替读者说出嫌弃，给出清醒回答）
↓
ENDING：不是A而是B金句 + 松弛哲学（落到一顿饭／一张脸／一个周末）
↓
今日话题互动
```

「不是A而是B」是厂牌最锋利的金句结构（5 篇复现），例如：
「不是因为它比别的恋爱更高级，而是因为它比别的恋爱更诚实」。

## 风格指纹（写后逐项数）

1. **画面密度**：每 200 字至少 1 个具体画面（有人、有动作、或有一句台词）
2. **人物样本**：全文 ≥ 3 个带名字带标签的访谈式案例
3. **口语词**：主打／确实／说白了／真香／自洽——1–3 处，不滥用
4. **对仗位置**：只在转折或收尾，不出现在开头
5. **ENDING 收尾**：道理落回一顿饭、一碗馄饨、一张脸、一个周末
6. **说教度为零**：全文无「我们应该」，改用「这才知道」「说白了就是」
7. **网感词 ≤ 3 个／篇**：一个梗用三次就油腻

七项里有两项不过，说明这篇没走完流程，回头补。

## 红线

每条都配了「改成什么」。只记住禁止，写作时反而更容易写出来。

| 别写 | 改成 |
|---|---|
| 「在这个 X 的时代」「总而言之」「不难发现」「赋能／抓手」 | 开篇直接上场景或一句共识句；要连接时用「说白了」「问题是」 |
| 每段都以观点句开头 | 每段从场景或一句吐槽起笔，观点句放段中或段尾 |
| 没有来源的案例 | 人物样本必须「标签＋名字＋场景＋原话」；素材不够就换选题，不补造 |
| 抒情散文式收尾（收在情绪上） | 收在一个具体场景上，再补一句松弛金句 |
| 比喻套比喻（超过一层） | 降维不升维：拿日常物比日常事，不用抽象概念比具体生活 |
| 每段都在解释「为什么」 | 每 200 字至少一个画面；解释段与场景段的比例不超过 1:2 |

写完跑一遍：`python3 tools/ai-flavor-checker.py --engine sanlian-writing 你的文章.md`
（本引擎门槛 < 30；引号访谈与「不是A而是B」在活人感文体里是加分项，不扣分。）

## 工作流

1. **选题**（三选一，全过才写）
   - 网络梗考古：刚发酵的流行说法 → 考古源头 → 验证人群 → 解构心态（黄金窗口：梗刚爆、还没写滥）
   - 现象命名：给旧现象起新名，命名即观点，名字即标题
   - 反共识观察：人人都说某件事不行 → 找例外 → 为什么它能活

   **完成判据——选题四问全过**：谁在经历？为什么现在流行？省了／花了多少钱（要有数字）？
   反映了什么心态转变？任一答不出，选题没成熟，回上一步。
2. **定标题**：从公式库选一，**先定标题再定内容**。
3. **定姿态**：自嘲／清醒／温柔，三选一，全文贯穿。
4. **收集素材**：≥ 3 个真实人物样本（标签＋名字＋场景＋原话）。
   **完成判据：素材不够就不写**——这一步是唯一的硬闸。
5. **写中段**：拆机制＋人物样本，每例解决一个「但是」。
6. **写收尾**：ENDING 标记＋不是A而是B＋松弛哲学＋互动提问。

最后：过一遍风格指纹七项 + 上表红线 + checker 评分。
