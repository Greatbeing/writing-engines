# 活人感写作 · 有体温的文字（v2.0 多源蒸馏版）

> 蒸馏源：三联生活实验室 11 篇代表作（2022-2026）
> 城市情感（姐弟恋 26-11）/ 消费（1元散装 26-11）/ 生活（脸基尼 26-05）/ 城市（绿化带 24-05）/ 饮食（干巴饭 24-05）/ 职场（喝大水 26-10）/ 消费心态（不烧心 26-10）/ 医疗（医保健身房 26-11）/ 房产理财（老破小收息佬 26-10）/ 健身（屁股 26-10）/ 剧评（年少有为 26-02）
>
> 一句话哲学：**文字要有活人感，不是修辞的堆砌，而是具体的人、具体的物、
> 具体的抱怨、具体的快乐。** 读者记住的不是观点，是态度。

## 此技能能做什么，不能做什么

**能做**：用这套引擎写城市观察文、公众号推文、观点随笔；让任何主题的文字带上
         活人感（口语化、幽默、具体、松弛）。

**不能做**：替代真实生活素材——活人感的地基是真实细节，没有素材时禁止凭空造案例；
           保证每篇都好笑——幽默是姿态，不是模板。

**素材声明v3**：11 篇多源蒸馏，原子操作多篇交叉验证。原文存档见
             `references/sources/local/`（11 篇）；语言层技法库见 `references/techniques.md`。
             厂牌级声音（作者：tweety/爱吃江米条/Lily/田梅梅/JOJO/迷人humen 等，选题与作者
             固定配对）。盲区：题材集中于城市青年生活方式（职场/消费/恋爱/健身/饮食），
             未覆盖访谈类/视频类内容；梗考古依赖网络热梗生命周期，梗过期后选题失效。

## 核心认知（4条，5篇交叉验证）

1. **活人感 = 具体性 × 情绪姿态**。抽象道理没人信，一个具体画面立刻可信。
   「情绪价值」没人记得，「弟弟睁大眼睛夸：姐姐，这个牛角包太好吃了」人人记得。
2. **姿态比辞藻重要**。自嘲、吐槽、清醒、温柔——读者记住的是态度，不是形容词。
3. **观点用场景证明，不用论证证明**。一个动物园场景 > 三段「防晒很重要」论证。
4. **金句是压缩生活的结论，不是装饰**。金句必须从场景里长出来，不能贴上去。

## 厂牌签名装置（结构层，5篇全部复现）

### 标题公式（5选1）
- **「XX的尽头：YY」** — 打工人过日子的尽头：1元大牌散装 / 防晒的尽头
- **「Y越X，越Z」** — 颜值越高，越爱"脸基尼"
- **「多少人…」** — 多少人去颐和园当"流水线格格"
- **「上海最夯XX」** — 上海最夯恋爱关系：姐弟恋（城市+地域限定词）
- **「XX的人，都在YY」** — 真松弛的新中产，都在吃干巴饭

### 开头公式
共识假装/普适困境（1-2句）→ 直接定义现象名词 → 抛出反共识观察。
禁止铺垫背景、禁止宏大叙事开场。

### 素材公式
全文 3-4 个真实人物样本撑论证，每人 = 标签（地域+年代+身份）+ 名字 + 一段具体场景 + 引号原话。
案例必须能反驳一个质疑（每个案例解决一个「但是」）。

### 收尾公式
「ENDING：」标记 → 「不是A而是B」金句 → 松弛哲学（落到具体生活） → 互动提问（今日话题）。

### 署名装置
- 图源credit 贯穿全文（图源@XX）——增强真人感与来源透明
- 大量「」访谈式引用——读者听到真人的声音
- 每篇至少 1 个递进梗或三连

## 选题引擎（写作前，v3.0）

选题三选一：
1. **网络梗考古**：网上刚发酵的流行说法 → 考古源头 → 验证人群 → 解构心态（黄金窗口：梗刚爆，还没写滥）
2. **现象命名**：给旧现象起新名，命名即观点，名字即标题（干巴lunch/脸基尼/微缩超市）
3. **反共识观察**：人人都说某件事不行 → 找例外 → 为什么它能活（姐弟恋/收息佬）

选题四问（全过才写）：这个现象谁在经历？为什么现在流行？省了/花了多少钱（数字）？
反映了什么心态转变？四问任一答不出，选题没成熟。

## 组合规则（骨架）

```
标题（公式库选一）
开头：共识假装 + 现象定义 + 反共识观察
  ↓
中段1：拆机制（为什么会出现——实用原因 + 心态原因）
  ↓
中段2：人物样本 ×3-4（每例解决一个质疑）
  ↓
质疑与反驳（替读者说出嫌弃，给出清醒回答）
  ↓
ENDING：不是A而是B金句 + 松弛哲学（落到一顿饭/一个周末/一张脸）
  ↓
今日话题互动
```

**不是A而是B句式**（厂牌最锋利的金句结构，5篇复现）：
- 「不是因为它比别的恋爱更高级，而是因为它比别的恋爱更诚实」
- 「他们放弃的不过是别人眼里的体面，换来的是自己脸上的舒坦」
- 「不是姐姐向下兼容，也不是弟弟躺赢。而是……自洽的默契」

## 风格指纹（写后逐项检查）

1. **画面密度**：每 200 字至少 1 个具体画面（有人、有动作、或有一句话台词）
2. **人物样本**：全文 ≥3 个带名字带标签的访谈式案例
3. **高频口语词**：主打/确实/说白了/真香/心照不宣/自洽——1-3 处，不滥用
4. **对仗只在转折或收尾**，不出现在开头
5. **结尾必有 ENDING 式松弛收尾**：道理落到一顿饭、一碗馄饨、一张脸、一个周末
6. **说教度为零**：全文无「我们应该」，用「这才知道」「说白了就是」代替
7. **网感词 ≤3 个/篇**：一个梗用三次就油腻

## 反AI味红线（硬指标）

- ❌ 禁止：「在这个X的时代」「总而言之」「不难发现」「毋庸置疑」「赋能/抓手」
- ❌ 禁止：每段首句都是观点句（活人感段落从场景或吐槽起笔）
- ❌ 禁止：无来源案例（活人感 = 真实感，假案例毁掉全文；人物样本必须标注标签+名字）
- ❌ 禁止：抒情散文式收尾（要收在具体场景，不收在情绪）
- ❌ 禁止：比喻超过一层（活人感比喻是降维的，不是升维的）
- ❌ 禁止：每段都在解释「为什么」（要有画面有声音有转折）

## 写作流程（六步）

1. **选题**：一个具体人群的普遍困境（沪漂恋爱 / 防晒麻烦 / 吃饭苦难 / 购物焦虑……）
2. **定标题**：从标题公式库选一，先定标题再定内容
3. **定姿态**：自嘲 / 清醒 / 温柔，三选一，全文贯穿
4. **收集素材**：≥3 个真实人物样本（标签+名字+场景+原话）——素材不够不写
5. **写中段**：拆机制 + 人物样本（每例解决一个质疑）
6. **写收尾**：ENDING 标记 + 不是A而是B + 松弛哲学 + 互动提问

写完后跑一遍风格指纹七项 + 反AI味红线。
