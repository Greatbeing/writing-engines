## 一、选题引擎（为什么总是这些选题）

**三类选题机制（11篇全覆盖）：**

### ① 网络梗考古（最主流，6/11篇）
网上出现一个流行说法/梗 → 立刻考古它的源头 → 验证它在真实人群中的表现 → 解构它反映的心态。

范例：
- 「大水理论」（韦神拎大水 → 全网效仿 → 省钱6000元 → 工位养生标尺 → 都市传说马斯克）
- 「不烧心」（AI短剧台词 → 全网复诵 → 翻译成人话 → 消费心态转变）
- 「臀权理论」（博主提出 → 科学依据臀大肌 → 精神内耗新解）

**梗考古的黄金窗口：梗刚发酵、还没被写滥时。**

### ② 现象命名（3/11篇）
给旧现象起新名字，命名即观点，名字本身就是选题。
- 糊弄饭 → 白人饭 → 干巴lunch（进化链命名）
- 小样 = 「微缩超市」「次抛装」「日租装」
- 脸基尼（电驴面罩的洋气重命名）

### ③ 反共识观察（2/11篇）
人人都说某件事不行 → 但有一个例外活得很好 → 为什么？
- 上海谈恋爱地狱难度 → 姐弟恋自洽
- 老破小收租不划算 → 年轻人转行「收息佬」

## 二、结构技巧

### 固定骨架
```
1. 共识假装开篇（1-2句，普适困境）
2. 现象定义（给名词，一句到位）
3. 拆成因（三层：省钱账 + 健康/科学依据 + 心态转变）
4. 人物样本 ×3-4（每例解决一个质疑）
5. 质疑桥（替读者说出「这不就是玩梗/神经病/父母早就说过」）
6. 反驳+心态升华（重新定义：这不是X，是Y）
7. ENDING 松弛哲学（落到具体生活）
8. 今日话题互动
```

### 篇幅分配
- 开头 10%（直奔主题，禁止铺垫）
- 成因拆解 30%（每一层都是独立的可传播观点）
- 人物样本 40%（全文的主体，观点都由案例说出来）
- 质疑+收尾 20%

### 「理论家族」扩篇幅法
一个梗不够，把它扩展成家族，同时制造笑点和篇幅：
「大水理论」→ 大睡理论 / 大菜理论 / 大蛋理论 → 「年轻人进入大理论时代」
「大锅、大菜、大蛋、大奶时代」→ 全民进入「不烧心时代」

## 三、句式技巧（语言层指纹）

### 1. 金句前置 + 独立行
论点写成可传播的网络金句，独立成行加粗：
> 「弱者才喝饮料，强者都是直接喝大水。」
> 「宁可少挣点，不能坏了规矩。」

### 2. 短促口语断言（4-8字，句号结尾，斩钉截铁）
- 「蒙上就是胜利。」
- 「脸罩一戴，谁也不爱。」
- 「管你什么原理。」

### 3. 引号引用仪式
全文 40%+ 篇幅是「」里的原话（网友/博主/人物样本/剧中台词），作者的观点借别人的嘴说出来。
引用来源必须具体：北漂Blue / 沪漂00后响响 / 上海程序员Louise / 北漂白领四文鱼。

### 4. 数字+具体物锚定
- 「2块钱的小水只有500毫升，3块钱的大水却直接给你1.5升」
- 「一年下来立省6000多元」
- 「244元/900g」「五秒钟就完事」
抽象的「省钱」没人信，具体到毫升和元才有说服力。

### 5. 荒诞解读法（日常物件 + 专业术语 = 笑点）
- 举 1.5L 大水 = 练二头肌；一手拎 2L = 「农夫行走」，练核心肌群
- 干巴面包硬度 = 「划伤食道被紧急送医」
- 防晒面罩 = 「物理外挂」「隐身模式」「接头暗号」

### 6. 科技/医学梗引用（半真半假，流行科普级）
- 皮质醇 / 血清素 / 水中毒 / 胃结肠反应 / 臀大肌 / 前额叶
用法：模糊来源（「有研究表明」「据说」），一句带过，不做论证主体。

### 7. 观念对比对仗
- 「以前…如今…」（以前小样是边角料，如今是反囤积宣言）
- 「扫货是上古神话里的阔气排场，小样才是老百姓过日子的实在归宿」
- 「一个人戴是神经病，两个人戴有点奇怪，三个人戴就成时尚单品」

### 8. 低姿态收尾金句
不喊口号，把道理压到最低处：
- 「成为一个最基本的尿尿不黄之人，比什么都重要。」
- 「只是为了今天这顿饭吃得香、周末过得有意思。」
- 「我舒服就行，管你怎么看。」

### 9. 双关梗（一词两义，标题级笑点）
- 股门 = 股票 / 屁股
- 大水 = 1.5L水 / 心态格局
- 不烧心 = 胃酸 / 良心（AI短剧台词梗）

### 10. 网络梗嵌句（一篇 ≤3 个）
主打 / 爆改 / 真香 / 贤者时间 / 精神氮泵 / 工位灵药 / 班味儿 / 摸鱼

## 四、节奏技巧

- **段落极短**：多数段落 2-4 句，一句一个信息；超过 6 句的段落罕见
- **笑点频率**：每 3-4 段必有一个「有人说」或一个荒诞解读
- **画面+声音密度**：每 200 字 ≥1 个画面 + ≥1 个引号
- **问句驱动**：段落间用反问推进（「谈何容易？」「至于让年轻人这么上头？」）
- **ENDING 仪式化**：固定用「ENDING：」标记收尾，形成可预期的仪式感

---

## 五、可信度工程（活人感的地基）

1. **人物样本实名化**：北漂/沪漂 + 年代 + 名字 + 身份标签——没有名字的案例不算案例
2. **数字必算**：任何「省钱/划算/性价比」论断必须配具体数字
3. **质疑必回应**：每个可能被读者吐槽的点，作者先吐槽并给出更清醒的回答
4. **科学引用半模糊**：「有研究表明」「据说」——不装专家，也不放弃智识感
5. **图源署名制**：图片一律「图源@XX」——增强真人感与透明度

## 六、进阶观察

- **选题生命周期**：梗发酵期选题 → 发酵中写作 → 热度回落发布（发布滞后于梗爆点约 1-3 天）
- **标题节奏**：标题公式 + 副标题/视觉符号（封面图源）
- **平台适配**：虎嗅/公众号字号一致，正文结构不变——厂牌以固定的声音跨平台输出
- **作者差异**：tweety（梗考古型：大水/不烧心/医疗）| 爱吃江米条（质感生活型：脸基尼/剧评）| Lily（北京生活型：屁股/流水线格格）| 田梅梅（饮食型：干巴饭）| JOJO（消费型：小样）——选题类型与作者固定配对，厂牌声音下仍有个人赛道

## 七、教训：道理型主题必须找到现象入口（2026-11-20）

**场景**：用户给一个道理（如「不去追求平庸的机会」），要求写成三联体。
**失败模式**：直接把道理硬套现象文模板——共识假装开头 + 名人背书（泰德/巴菲特/芒格）+ 道理排比。
读起来像成功学合集：有骨架、没有血肉。诊断：**活人感的地基是现象，不是道理。**

**成功解法**（重写版）：
1. 先找正在发酵的真实现象做入口——「无人扶我青云志，我就自己搞点事」（10月底热梗）
2. 把道理**转译**成现象结论：接不住的才叫平庸机会（重新定义）
3. 人物样本全部换成现象里的真人真话（烤肠摊主/山脚小卖部/职场调查原话），名人只作一句旁证
4. 金句全部来自素材原话，自己写的话只在 ENDING 憋两行

**判定规则**：用户给道理 → 问自己「这个道理现在有什么现象正在替它说话？」找不到现象入口，就不要写三联体——换 ljg-plain 或官方体。
