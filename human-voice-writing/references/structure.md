# 厂牌签名装置

> 三联生活实验室的结构层指纹。11 篇里 5 篇以上复现的固定装置。
> 这些是「照着填就能像」的部分——也正因为如此，**只有骨架不足以成为好文章**，
> 骨架的作用是让你不必分心去想结构，把力气全花在具体的人身上。

## 一、标题公式（5 选 1）

先定标题，再定内容。标题定不下来，说明选题还没成形。

| 公式 | 例 |
|---|---|
| 「XX 的尽头：YY」 | 打工人过日子的尽头：1 元大牌散装／防晒的尽头 |
| 「Y 越 X，越 Z」 | 颜值越高，越爱「脸基尼」 |
| 「多少人…」 | 多少人去颐和园当「流水线格格」 |
| 「上海最夯 XX」 | 上海最夯恋爱关系：姐弟恋（城市＋地域限定词） |
| 「XX 的人，都在 YY」 | 真松弛的新中产，都在吃干巴饭 |

标题公式的共性：**带一个具体名词 + 一个反常识判断**。
纯情绪标题（《看完我沉默了》）和纯结论标题（《年轻人为什么不爱结婚了》）都不用。

## 二、开头公式

```
共识假装／普适困境（1–2 句）→ 直接定义现象名词 → 抛出反共识观察
```

三条禁令（对应 SKILL.md 红线）：

- 不铺垫背景（「随着社会的发展」这类开场直接删）
- 不宏大叙事开场（「这是一个时代的选择」）
- 第一句就要有人在做事、或者有一句大家都说过的话

## 三、素材公式

全文 **3–4 个真实人物样本**撑起论证。每个样本四件套：

```
标签（地域＋年代＋身份）+ 名字 + 一段具体场景 + 引号原话
```

关键约束：**每个案例必须反驳一个质疑**（每个案例解决一个「但是」）。

为什么：读者的抵抗是逐个产生的——「但是穷人哪有钱买脸基尼」「但是戴那个不热吗」。
一个案例解决一个「但是」，抵抗被逐个拆掉；三个案例都解决同一个「但是」，
就是同义反复。

## 四、收尾公式

```
「ENDING：」标记
→ 「不是A而是B」金句
→ 松弛哲学（落到具体生活）
→ 互动提问（今日话题）
```

「不是A而是B」的语料样本（5 篇复现）：

- 「不是因为它比别的恋爱更高级，而是因为它比别的恋爱更诚实」
- 「他们放弃的不过是别人眼里的体面，换来的是自己脸上的舒坦」
- 「不是姐姐向下兼容，也不是弟弟躺赢。而是……自洽的默契」

结构规律：**A 是别人以为的理由，B 是真实理由，且 B 比 A 低、比 A 具体。**
写成「不是A而是更高级的B」就失效了——那是在抬升，不是松弛。

## 五、署名装置

三个小装置，负责「真人感」与「来源透明」：

1. **图源 credit 贯穿全文**（图源 @XX）——增强真人感，也让转载可追溯
2. **大量「」访谈式引用**——读者听到的是真人的声音，不是作者的转述
3. **每篇至少 1 个递进梗或三连**——保证笑点密度，但不超过 3 处

> 注：「大量引号引用」在 checker 里对活人感引擎是**加分项**（
> `engine_profiles.json` 的 `dialogue` reward = 2.0），不会被当成 AI 腔扣分。
> 这正是 v0.2 相对 v0.1 的关键修正。

## 六、这些装置什么时候不该用

- **写特稿时**：署名装置是活人感的；特稿要「记者消失」，不标图源、不加互动提问。
- **写官方体时**：收尾的互动提问换成结构化表态（三句排比），松弛哲学换成升维句。
- **素材只有二手转述时**：素材公式要求「场景＋原话」，二手转述凑不出来。
  这时换选题，或者换引擎——不要把转述包装成访谈。
