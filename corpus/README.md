# corpus · 语料统计（L1 表层语言）

> 这个目录回答一个问题：**「这个作者句子短」——短到多少？**

## 为什么要有它

仓库里的 182 个原子是从阅读记忆里写出来的，不是从语料里数出来的。
这正是 8 个引擎的 `references/sources.md` 都标着「引文未逐字核对」的根本原因：
原子的说法没有可核对的数字支撑，只有印象。

`tools/corpus_stats.py` 补上那一半。它不做判断，只出数据；判断仍然写在
`references/atom-ops.md` 里，但现在可以被数字反驳。

## 只有统计量，没有原文

每份 `语言DNA.md` 里只有：句长、句长分布、标点密度、段落节奏、高频二字词表。
**没有任何原文句子**——原文不入库（见 `.gitignore` 与 `NOTICE.md`），
而统计量与孤立的词不构成对作品的复制。

语料在本机 `tools/tests/fixtures/local/<engine>-<n>.txt`，首行是来源 URL。
想自己核对，打开那里；想复现，跑 `python tools/corpus_stats.py --write`。

## 生成

```bash
python tools/corpus_stats.py            # 只看数字
python tools/corpus_stats.py --write    # 同时写 corpus/<engine>/语言DNA.md 与 stats.json
python tools/corpus_stats.py --engine luxun
```

几个可以直接看出来的事实：

- **公文与人民日报是另一套节奏**：平均句长 48.3 / 39.5，长句近三成。给这两个引擎写的稿子，句子短了反而不像。
- **张爱玲与苏轼的短句最多**（31% / 36%），印证两家的「短句断语」与「白话短句」说法。
- **余华平均句长 33.3，长句 21%**，比直觉高。检视语料后确认是《活着》节选中成段的叙述描写所致——「零度叙述」讲的是不动声色，不是句子短。**这条修正了一个常见误解。**

## 局限（读之前先看）

1. **样本小。** 每篇 3000–6000 字，每个引擎 2–3 篇。够看节奏，不够看作家的全部面貌。
2. **篇章差异大。** 同一作者写不同体裁，数字会跳。苏轼那三篇是文言原文，长度天然短，不能直接与白话作者比较。
3. **节选偏差。** 抓取的是公开可见的节选，不等于全文分布。
4. **清洗不易。** 转载页可能混入平台声明；已尽量清除，但个别残留会影响标点密度。
5. **只覆盖 12 个引擎。** 特稿、人味、脱口秀没有语料，暂无统计。

## 怎么用

- 写某个引擎时，句长与标点密度对得上本表；对不上就是「像了样子、不像节奏」。
- 与表里差距超过 30% 时，先查是不是混进了别的文体的习惯。
- 表里没有的东西（怎么想、怎么选材），看 `atoms/index.json` 与各引擎 `references/sources.md`。
