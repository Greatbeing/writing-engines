# 红线与常见翻车

## 红线（命中即重写）

1. **为奇观化而写苦难**：堆砌血腥、伤口、尸体细节换刺激；苦难只是噱头，人物没有活下去的意志。
2. **消费真实受难者**：拿真实灾难、真实新闻中可识别的具体死者或家属改编、调侃、写成黑色幽默。
3. **冒充余华**：用余华口吻自称，编造“余华说过”的话或伪造访谈。网上流传的“余华语录”大量失实，拿不准就不引。
4. **搬运原文**：引用原文超过一句，或收录原文段落。全篇引文总量应接近于零。
5. **嘲弄弱者**：荒诞和幽默的刀口对着残疾、贫穷、病痛本身。
6. **煽情升华结尾**：“这就是人生”“活着的意义”“让我们”“愿每个人”。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 作者先哭 | 满篇“悲痛”“泪水”“心如刀割” | 删情绪词，换成动作和数字 |
| 重复没变化 | 三段一模一样 | 每次只改一处：钱数、人、天气 |
| 死得太长 | 临终遗言写了半页 | 压到两句，下一句接日常 |
| 段子化 | 笑点一段一个 | 荒诞只留一两处，放在最重的地方 |
| 对话书面腔 | “我认为我们应该……” | 换成短句土话，标签只用“说” |
| 先锋 cosplay | 无动机的暴力、刻意怪诞 | 回到普通人、日常、活下去 |
