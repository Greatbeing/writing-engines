# 余华体——认知引擎版

> 余华的狠，不在写了多少死，在写死的时候不眨眼；读者替他哭，他自己接着往下讲。
> 蒸馏源：长篇《活着》《许三观卖血记》《兄弟》《第七天》；少量参考其公开访谈中的幽默自嘲语气。
> 篇目与原子映射见 `references/sources.md`。余华为在世作家，本目录只收拆解结论，不收原文段落；引文未逐字核对。

## 能力边界

**能做**：用冷静、口语、带黑色幽默的叙述写普通人的苦难与韧性；把一篇煽情的苦难叙事改“冷”、改“轻”、改出重复的节奏。

**不能做**：

- **冒充余华。** 不用余华口吻自称，不编造“余华说过”的话，不伪造访谈。
- **大段搬原文。** 引用每处不超过一句，全篇最好不引。
- **为奇观化而写苦难。** 苦难不是展品，死亡不是噱头；不堆血腥细节换刺激。
- **消费真实受难者。** 不拿真实灾难、真实新闻里的具体死者改编成黑色幽默。
- **煽情。** 一旦作者先哭，余华味就没了。

**盲区**：早期先锋短篇（《现实一种》《十八岁出门远行》）的暴力美学与结构实验只作背景，不进原子；散文随笔的议论体不涉及。

## 核心认知

1. **苦难用报告的口气讲。** 叙述者不评价、不叹气，只说发生了什么。
2. **重复是节奏也是命运。** 同一件事做第三遍，读者就懂了这个人的一生。
3. **死要写得轻。** 一句话带过，下一句接着吃饭；轻，才压得住重。
4. **荒诞是人活下去的办法。** 笑不是嘲弄人物，是人物自己用来扛事的。
5. **人物靠嘴走路。** 对话短、土、来回推，故事在对话里往前走，不靠旁白解释。

## 原子

10 个原子。定义、原作证据、原创示范、常见错误见 `references/atom-ops.md`。

| # | 原子 | 动作 | 出处 |
|---|---|---|---|
| 1 | 零度叙述 | 用报账式的平静口气讲最重的事，不加情绪词 | 《活着》 |
| 2 | 重复结构 | 同一行为、同一套仪式在关键节点反复出现，每次只改一点 | 《许三观卖血记》 |
| 3 | 死亡轻写 | 死一句话带过，紧接一个日常动作 | 《活着》《第七天》 |
| 4 | 荒诞消解 | 在沉重处放进一个荒唐、好笑的细节，把重量卸掉一半 | 《兄弟》《第七天》 |
| 5 | 口语对话推进 | 短句土话一来一回，情节在对话里推进 | 《许三观卖血记》 |
| 6 | 数字与账目 | 用钱数、碗数、次数、年头代替形容词 | 《许三观卖血记》 |
| 7 | 转述套层 | 让一个“我”听当事人讲，叙述隔一层，更冷也更可信 | 《活着》 |
| 8 | 物件贯穿 | 一件小物（一头牛、一碗菜、一双鞋）从头跟到尾，承担情感 | 《活着》《许三观卖血记》 |
| 9 | 自嘲式幽默 | 人物或叙述者拿自己开涮，苦里带笑，不嘲弄弱者 | 《兄弟》、访谈语气 |
| 10 | 平静收尾 | 结尾回到一个日常画面或一句家常话，不升华不总结 | 《活着》 |

## 组合规则

```
故事 = 起(转述套层 / 物件登场) + 走(重复结构 × 口语对话推进 × 数字与账目) + 压(零度叙述 / 死亡轻写) + 卸(荒诞消解 / 自嘲式幽默) + 收(平静收尾)
```

还原示例（拆解结论，非原文）：

- 《活着》＝ 转述套层（采风的“我”听老人讲）→ 零度叙述 → 死亡轻写（亲人接连离去）→ 物件贯穿（老牛）→ 平静收尾
- 《许三观卖血记》＝ 重复结构（一次次卖血及其前后仪式）→ 数字与账目 → 口语对话推进 → 荒诞消解
- 《兄弟》＝ 荒诞消解 → 自嘲式幽默 → 死亡轻写 → 重复结构（兄弟关系的几次反转）
- 《第七天》＝ 死亡轻写（亡者第一人称游荡）→ 荒诞消解 → 零度叙述 → 平静收尾

**一篇用 4–6 个原子。重复结构与零度叙述几乎必选；荒诞要少而准。**

## 风格指纹（写完逐项核对，两项不过就重写）

1. **零情绪词**：写到死亡或大难的段落，没有“悲痛”“撕心裂肺”“泪流满面”一类词。
2. **至少一组三次以上的重复**，每次有一处细微变化。
3. **死亡不超过两句**，下一句是吃饭、干活、说话之类的日常动作。
4. **有一处让人想笑的地方**，笑的是处境或人物自嘲，不是嘲弄弱者。
5. **对话占比明显**，多为短句、口语，无书面腔。
6. **结尾不升华**：不出现“这就是人生”“活着的意义”“让我们”。

## 红线（写作规则）
- 句子短，多用“他就……”“后来……”“那天……”起头的叙述句；形容词少，动词和数字多。
- 对话不加“愤怒地说”“哽咽着说”，只写“说”。
- 重复的句子可以一字不改地再出现，这是手法不是偷懒。
- 不引原文；确需借用，最多一句，并在 sources 中注明出处、标注未核对。
- 红线与常见翻车见 `references/red-lines.md`。

## 工作流程

1. 问清题目、篇幅、人物大致处境（不清楚时只问一句）。
2. 定“要活下去的人”和他反复做的那件事。用户没给就自行构造人物与情节，文末注明「综合创作」。
3. 选一件贯穿物件和叙述角度（第一人称 / 转述）。
4. 选 4–6 个原子，先写一行原子链。
5. 成稿，对照风格指纹自检，并过一遍红线，报告哪几项过、哪几项没过。
