## 概览

依据《党政机关公文格式》（GB/T 9704-2012）。公文由**版头、主体、版记**三部分组成：首条分隔线以上为版头，首条分隔线（不含）至版记之间为主体，末页首条分隔线以下为版记。

凡标注“实务做法”的内容不是国标原文，是常见的 Word 设置方式，以本厅文书部门的要求为准。

## 页面设置

- **纸张**：A4（210mm × 297mm）
- **版心**：156mm × 225mm
- **页边距**：天头（上白边）37mm±1mm，订口（左白边）28mm±1mm；下、右白边由版心尺寸推出（约35mm、26mm）
- **行字数**：国标规定一般**每面22行、每行28字**，撑满版心，特定情况可作适当调整
- 实务做法：Word 中行距设为“固定值 28.95 磅”左右、字符间距不缩放，可近似达到 22×28；不同字体可能需微调

## 版头

按出现顺序：

| 要素 | 规则 |
|---|---|
| 份号 | 涉密公文应标注；6位3号阿拉伯数字，顶格编排在版心左上角第一行 |
| 密级和保密期限 | 3号黑体，顶格编排在版心左上角第二行；保密期限中的数字用阿拉伯数字 |
| 紧急程度 | “特急”“加急”，3号黑体，顶格编排在版心左上角；与密级同时出现时，按份号、密级和保密期限、紧急程度的顺序自上而下 |
| 发文机关标志 | 发文机关全称或规范化简称后加“文件”二字（或只用机关名称）；红色小标宋，居中，上边缘至版心上边缘35mm |
| 发文字号 | 机关代字＋年份＋发文顺序号，如“×发〔2026〕×号”；年份用**六角括号〔〕**，顺序号不编虚位（1不写成01）、不加“第”；3号仿宋，在发文机关标志下空二行居中 |
| 签发人 | **上行文必须标注**。此时发文字号居左空一字，签发人居右空一字；“签发人”3号仿宋，后加全角冒号，姓名用3号楷体 |
| 版头分隔线 | 发文字号之下4mm处，与版心等宽的红色分隔线 |

> 发文字号中的机关代字各单位不同，按本单位文书规定填写，**不要自行编造**；不确定时留“×”让用户填。

## 主体

### 标题

- 结构：发文机关名称 + 事由 + 文种（发文机关名称在有版头时可省略）
- 2号小标宋，红色分隔线下空二行居中
- 回行时要词意完整、排列对称、长短适宜，排成梯形或菱形，不要把一个词拆在两行
- 除法规、规章名称加书名号外，一般不用标点

### 主送机关

- 标题下空一行，左侧顶格，最后一个主送机关名称后加全角冒号
- 多个主送机关之间：同类用顿号，不同类用逗号
- 写法示例：`各市、县（区）××局，厅机关各处室：`（以当期实际机构名称为准）

### 正文

- 3号仿宋，每个自然段左空二字，回行顶格
- 结构层次序数：第一层“一、”（黑体）→ 第二层“（一）”（楷体）→ 第三层“1.”（仿宋）→ 第四层“（1）”（仿宋）
- 层次不跳级；层次少时可只用“一、”和“（一）”，或只用“一、”和“1.”
- 数字：统计数字、金额、百分比用阿拉伯数字；成语、惯用语、概数用汉字（如“十四五”“三四个”）

### 附件说明

- 正文下空一行左空二字编排“附件”二字，后标全角冒号和附件名称
- **只有一个附件时不编序号**：`附件：××专项资金分配表`
- 多个附件用阿拉伯数字序号：`附件：1. ××××`，回行与上一行附件名称首字对齐
- **附件名称后不加标点符号**

### 发文机关署名、成文日期和印章

- 成文日期用阿拉伯数字将年、月、日标全，年份写全称，月日不编虚位：`2026年11月25日`（不写“2026年11月05日”，也不写“二〇二六年”）
- **加盖印章的公文**：成文日期一般右空四字编排；发文机关署名以成文日期为准居中编排；印章端正、居中下压署名和成文日期，使署名和日期居印章中心偏下位置，印章顶端距正文（或附件说明）一行之内
- **不加盖印章的公文**：发文机关署名右空二字编排，成文日期在署名之下另起一行，首字比署名首字右移二字；如成文日期长于署名，应使成文日期右空二字，署名相应左移
- 联合行文需加盖多个印章时，主办机关印章在前，印章互不相交或相切，间距不大于3mm
- 正文排完后空间不足以编排署名、日期和印章时，应调整行距字距处理，**不得在空白页上只排日期和印章**，并在日期下一行左空二字注明“（此页无正文）”

### 附注

- 有附注时（如请示中的联系人和电话），居左空二字加圆括号，编排在成文日期下一行
- 请示应在附注处注明联系人姓名和电话

### 附件正文

- 另面编排，“附件”二字及序号用3号黑体顶格编排在版心左上角第一行
- 附件标题居中编排在版心第三行，格式要求与正文一致

## 版记

版记位于公文最后一页（偶数页），最后一个要素置于最后一行。

| 要素 | 规则 |
|---|---|
| 分隔线 | 首条和末条为粗线（推荐0.35mm），中间为细线（推荐0.25mm），与版心等宽 |
| 抄送机关 | 4号仿宋，左右各空一字，“抄送”后加全角冒号，末尾加句号；抄送机关之间用逗号或顿号 |
| 印发机关和印发日期 | 4号仿宋，印发机关左空一字，印发日期右空一字，日期后加“印发”二字，如“2026年11月25日印发” |

## 页码

- 4号半角宋体阿拉伯数字，数字左右各放一条一字线，如“— 1 —”
- 一字线上距版心下边缘7mm
- **单页码居右空一字，双页码居左空一字**
- 公文的版记页前有空白页时，空白页和版记页均不编排页码

## 字体字号速查

| 元素 | 字体 | 字号 |
|---|---|---|
| 发文机关标志 | 小标宋（红色） | 由发文机关酌定，一般小于22mm×15mm |
| 份号、发文字号、签发人（“签发人”三字） | 仿宋 | 三号 |
| 签发人姓名 | 楷体 | 三号 |
| 密级、紧急程度 | 黑体 | 三号 |
| 标题 | 方正小标宋简体 | 二号 |
| 主送机关、正文、署名、成文日期、附注 | 仿宋_GB2312 | 三号 |
| 一级标题“一、” | 黑体 | 三号 |
| 二级标题“（一）” | 楷体_GB2312 | 三号 |
| 三、四级标题“1.”“（1）” | 仿宋_GB2312 | 三号 |
| 附件标识（附件页左上角） | 黑体 | 三号 |
| 抄送、印发机关和日期 | 仿宋_GB2312 | 四号 |
| 页码 | 宋体（半角） | 四号 |

## 示例

### 上行文版头示意（请示、报告）

```
                  ××省××厅文件

 ×发〔2026〕×号                     签发人：×××
——————————————————————————（红线）

            ××省××厅关于××××的请示

省政府：
    ……
```

### 通知（下行文）

```
            ××省××厅关于××××的通知

各市、县（区）××局：

    为……，根据……，现将有关事项通知如下：

    一、××××
    （一）××××
    1. ××××

    二、工作要求
    ……

    附件：××××表

                                    ××省××厅
                                  2026年11月25日

——————————————————————————（粗线）
 抄送：××××。
——————————————————————————（细线）
 ××省××厅办公室                 2026年11月25日印发
——————————————————————————（粗线）
```

### 请示（上行文）结构

```
            ××省××厅关于××××的请示

省政府：

    ……（缘由），现将有关事项请示如下：

    一、基本情况
    二、请示事项
    三、理由和依据

    妥否，请批示。

                                    ××省××厅
                                  2026年11月25日
    （联系人：×××，联系电话：××××××××）
```
