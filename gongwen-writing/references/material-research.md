# 素材调研方法

## 概览

动笔前的素材调研让内容有据可依，不凭空编造。调研的轻重按任务分级（见 SKILL.md“任务分级”）：润色和改写只需通读原稿；新起草才走完整三步。

## 调研三步法

### 第一步：盘点已有素材

- 用户提供的文件（政策文件、领导讲话、数据报表、往期公文等），**必须用文件读取工具完整读取**后再提炼，不凭文件名猜测内容
- 用户在对话中粘贴的文字材料，直接通读
- 多份材料时，先列清单标注每份的用途（政策依据 / 数据支撑 / 参考文风）

### 第二步：补齐缺口

- 对照公文类型判断还缺什么：
  - 请示 / 报告 → 缺政策依据、数据支撑
  - 通知 / 决定 → 缺事项细节、时间地点、责任分工
  - 函 → 缺对方单位准确名称、商洽事项背景
- 缺政策依据且用户同意时，可用可用的网络检索工具查权威来源，引用须注明出处，**不编造文号**
- 优先的权威来源：
  - 国家法律法规数据库（flk.npc.gov.cn）
  - 中国政府网（gov.cn）的政策文件库
  - 上级业务主管部门、本级政府及本单位官网的政策发布
- 缺业务数据（金额、户数、项目清单）时，向用户索要，**绝不凭空填充数字**；可先用“××万元”占位并在交付时列出待填清单

### 第三步：产出素材摘要

动笔前先整理一份简短摘要（内部使用，不必交付），包含：

- **核心事实**：这件事的关键信息（时间、地点、人物、数据）
- **政策依据**：可用的文件名称、文号、关键条款
- **可用表述**：从原始材料中摘出的规范提法
- **背景要点**：来龙去脉、相关方立场

## 边界

- 检索到的政策须核实有效性（是否已废止、是否被新文件替代），过时文件不作为依据
- 网上检索不到的内部文件，不要猜测其内容或文号
- 涉密材料不在摘要中扩散，仅提炼非密要点；涉密内容不得粘贴到联网工具中检索
- 素材不足时如实告知用户缺口，不硬写
