## 概览

根据《党政机关公文处理工作条例》，党政机关公文共有15种法定类型。本规范详细说明每种类型的定义、适用范围和写作要点。

## 15种法定公文类型

### 1. 决议
- **定义**：适用于会议讨论通过的重大决策事项
- **适用范围**：党代会、人代会等重要会议通过的决策
- **特点**：具有权威性和约束力

### 2. 决定
- **定义**：适用于对重要事项作出决策和部署
- **适用范围**：重大人事任免、重要事项安排
- **特点**：决策性强，执行要求明确

### 3. 命令（令）
- **定义**：适用于公布行政法规和规章、宣布施行重大强制性措施、批准授予和晋升衔级、嘉奖有关单位和人员
- **适用范围**：由依法具有发令权的机关或领导人发布（如国务院、国务院各部门、有规章制定权的地方人民政府等），按法定权限行使
- **特点**：强制性最强；厅内日常工作基本用不到，不要轻易建议使用

### 4. 公报
- **定义**：适用于公布重要决定或者重大事项
- **适用范围**：党代会、人代会等重要会议成果
- **特点**：公开性强，影响面广

### 5. 公告
- **定义**：适用于向国内外宣布重要事项或者法定事项
- **适用范围**：国家机关对外发布重要信息
- **特点**：面向公众，内容重要

### 6. 通告
- **定义**：适用于在一定范围内公布应当遵守或者周知的事项
- **适用范围**：行政机关向社会公布事项
- **特点**：区域性，针对性强

### 7. 意见
- **定义**：适用于对重要问题提出见解和处理办法
- **适用范围**：行文方向灵活，可上行、下行、平行
  - 上行意见：作为下级向上级提出的建议，上级应当对其办理或答复，**按请示性公文的程序和要求办理**
  - 下行意见：作为指导或部署，明确要求下级执行的照办，没有明确要求的参照执行
  - 平行意见：供对方参考
- **特点**：指导性、建议性；同一事项要先想清楚是哪个方向，语气差别很大

### 8. 通知
- **定义**：适用于发布、传达要求下级机关执行和有关单位周知或者执行的事项
- **适用范围**：最常用公文类型之一
- **特点**：使用频率高，适用范围广

### 9. 通报
- **定义**：适用于表彰先进、批评错误、传达重要精神和告知重要情况
- **适用范围**：典型事例宣传或警示
- **特点**：教育性强

### 10. 报告
- **定义**：适用于向上级机关汇报工作、反映情况
- **适用范围**：下级向上级汇报
- **特点**：陈述性，不需批复

### 11. 请示
- **定义**：适用于向上级机关请求指示、批准
- **适用范围**：需要上级决策的事项
- **特点**：请求性，需批复

### 12. 批复
- **定义**：适用于答复下级机关请示事项
- **适用范围**：上级对下级请示的回复
- **特点**：针对性强，一事一批

### 13. 议案
- **定义**：适用于各级人民政府按照法律程序向同级人民代表大会提请审议事项
- **适用范围**：政府向人大提交审议
- **特点**：程序性强

### 14. 函
- **定义**：适用于不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项
- **适用范围**：平行机关或不相隶属机关之间
- **特点**：灵活性高

### 15. 纪要
- **定义**：适用于记载会议主要情况和议定事项
- **适用范围**：需要传达、执行会议议定事项的会议（办公会、专题会、协调会等）
- **特点**：概括性和纪实性。**纪要不等于会议记录**：记录是原始过程的逐项记载，纪要是对主要精神和议定事项的提炼整理，不照搬发言，不写与议定事项无关的讨论过程
- **格式提示**：纪要一般不加盖印章，常用“会议认为”“会议指出”“会议议定”领起

## 常用公文写作要点

### 通知类
- **结构**：标题 + 主送机关 + 正文（背景+事项+要求）+ 落款
- **语言**：简洁明了，要求明确
- **注意**：事项要具体，时间要明确

### 报告类
- **结构**：标题 + 主送机关 + 正文（情况+做法+问题+计划）+ 落款
- **语言**：客观真实，数据准确
- **注意**：不需批复，结尾用"特此报告"

### 请示类
- **结构**：标题 + 主送机关 + 正文（背景+事项+理由）+ 落款
- **语言**：恳切诚恳，理由充分
- **注意**：一文一事，结尾用"妥否，请批示"

### 函件类
- **结构**：标题 + 主送机关 + 正文（缘由+事项+期望）+ 落款
- **语言**：礼貌得体，语气平和
- **注意**：平等协商，不强加于人

### 会议纪要类
- **结构**：标题 + 会议基本信息（时间、地点、主持人、出席人员）+ 主要精神 + 议定事项 + 落款
- **语言**：提炼概括，重点突出
- **注意**：忠实于会议议定的结论，不添加个人观点；议定事项要写清牵头单位、配合单位和完成时限

### 请示和报告的区分
- 要上级“拍板”的用请示，只是“告知”的用报告
- 请示一文一事、事前行文、原则上只主送一个上级机关、不抄送下级
- 报告**不得夹带请示事项**

## 常见行文关系速查

以省级政府组成部门（“××厅”）为例。实际机构名称和隶属关系以当期为准，拿不准时提醒用户核实。

| 场景 | 方向 | 文种 |
|---|---|---|
| 向本级政府请求批准事项 | 上行 | 请示（需签发人） |
| 向本级政府或上级业务主管部门汇报工作 | 上行 | 报告（需签发人） |
| 向下级对口部门部署工作 | 下行（业务指导） | 通知 |
| 对下级对口部门的请示作出答复 | 下行 | 批复 |
| 与同级其他部门商洽工作、征求意见、答复询问 | 平行 | 函 |
| 答复同级其他部门的申请、审批事项 | 平行（不相隶属） | 函（复函），**不用批复** |
| 对本系统工作提出指导性措施 | 下行 | 意见 / 通知 |
| 厅长办公会、专题会议 | — | 纪要 |

要点：
- 同级部门之间**不相隶属**，相互之间请求批准、答复审批一律用“函”，不用“请示”“批复”
- 部门对下级对口部门多为业务指导关系；以部门名义向下级政府行文要谨慎，一般应以本级政府或政府办公厅名义

## 示例

### 通知示例结构
```
关于XXX工作的通知

各有关单位：

    为进一步做好XXX工作，现将有关事项通知如下：

    一、工作目标
    （具体内容）

    二、主要任务
    （具体内容）

    三、工作要求
    （具体内容）

    请各单位高度重视，认真组织实施。

                                    XXX办公室
                                  2024年1月15日
```

### 报告示例结构
```
关于XXX工作的报告

XX上级机关：

    根据XX要求，现将XXX工作情况报告如下：

    一、基本情况
    （具体内容）

    二、主要做法
    （具体内容）

    三、存在问题
    （具体内容）

    四、下一步工作计划
    （具体内容）

    特此报告。

                                    XXX单位
                                  2024年1月15日
```

### 请示示例结构
```
关于XXX事项的请示

XX上级机关：

    为解决XXX问题，现请示如下：

    一、背景情况
    （具体内容）

    二、请示事项
    （具体内容）

    三、理由和依据
    （具体内容）

    妥否，请批示。

                                    XXX单位
                                  2024年1月15日
```
