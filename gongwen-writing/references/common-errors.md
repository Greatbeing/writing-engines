# 公文常见硬伤清单

## 概览

自我审查阶段逐项核对下列硬伤。这些是公文中最易出错、也最影响严肃性的问题，发现即改。

## 一、文种使用

- [ ] 文种是否选对：请求批准用“请示”而非“报告”；答复下级请示用“批复”；不相隶属机关商洽或请求批准用“函”，不用“请示”“通知”
- [ ] 答复不相隶属机关的申请、审批事项，用“复函”，不用“批复”
- [ ] 是否一文一事：请示必须一文一事，不得在一份请示中夹带多个不相关事项
- [ ] 报告是否夹带请示事项：报告中不得夹带请示事项
- [ ] 上行“意见”是否按请示的要求写（理由、事项、结语）
- [ ] 纪要是否写成了流水账式的会议记录

## 二、结语规范

- [ ] 请示结语：用“妥否，请批示”“以上请示，请予审批”，不用“特此报告”
- [ ] 报告结语：用“特此报告”，不用“请批示”
- [ ] 通知结语：用“特此通知”或执行要求；函用“特此函达”“请予支持”“盼复”等，复函用“特此函复”
- [ ] 批复结语：用“此复”“特此批复”

## 三、行文关系

- [ ] 主送机关是否准确：上行文原则上单一主送，不多头主送
- [ ] 是否越级行文：非特殊情况不越级，越级时须抄送被越过的机关
- [ ] 请示是否抄送了下级机关（不应抄送）
- [ ] 是否以部门名义向下级政府（而非下级对口部门）直接发布指令性公文
- [ ] 语气是否匹配：上行文恭敬、下行文明确、平行文平和，不得上行文傲慢或下行文商量

## 四、格式要素

- [ ] 标题是否完整：发文机关 + 事由 + 文种，文种不可缺失
- [ ] 标题标点：除法规规章名称用书名号外，一般不用标点；回行不拆词
- [ ] **上行文是否标注了签发人**
- [ ] 发文字号：年份用六角括号〔〕（不是方括号[]或圆括号），序号不编虚位、不加“第”；机关代字未编造
- [ ] 层次序号是否规范：一、（一）、1.、（1）四级，不跳级不混用；“一、”后不再加标点，“1.”用英文句点
- [ ] 附件说明：单个附件不编序号；附件名称后不加标点
- [ ] 成文日期：用阿拉伯数字且月日不编虚位，如 2026年11月25日，不用“二〇二六年”“11月05日”
- [ ] 署名和日期的位置是否与有无印章相符
- [ ] 请示是否在附注中注明联系人和电话
- [ ] 版记要素：抄送机关末尾句号、印发机关和印发日期（“××印发”）、粗细分隔线
- [ ] 数字与计量单位：统计数字用阿拉伯数字，计量单位用法定单位；金额单位全文统一（元/万元/亿元）

## 五、内容质量

- [ ] 是否有错别字、语病、标点误用
- [ ] 事项是否具体可执行：时间、地点、责任人、要求是否明确
- [ ] 数据是否准确、有出处，无凭空编造；金额合计是否等于分项之和
- [ ] 引用的文件名称和文号是否真实有效（不确定的标“待核”，不编造）
- [ ] 是否涉及敏感内容需提醒核实口径（资金规模、人事、未公开政策）

## 使用方式

审查时逐项核对，命中问题立即修正后再交付；无法判断的（如政策口径、文号真伪、机关代字）提示用户核实，不擅自定论。
