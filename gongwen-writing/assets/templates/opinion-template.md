# 意见模板

意见可上行、下行、平行，先确定方向：

- **下行**：对下级提出指导性措施，明确要求执行的照办
- **上行**：向上级提出建议，按请示的程序和要求办理（标注签发人，结尾可用“以上意见如无不妥，请批转各地执行”）
- **平行**：供对方参考

## 基本结构（下行）

```markdown
[发文机关]关于[事由]的意见

[主送机关]：

    为[目的]，根据[依据]，现提出如下意见：

    一、总体要求
    二、主要任务
    （一）……
    （二）……
    三、保障措施

                                    [发文机关]
                                  [成文日期]
```

## 使用示例（下行）

```markdown
××省××厅关于进一步加强××资金管理的意见

各市、县（区）××局：

    为进一步规范××资金管理，提高资金使用效益，根据××规定，现提出如下意见：

    一、总体要求
    ……

    二、主要任务
    （一）健全分配机制。……
    （二）强化绩效管理。……

    三、保障措施
    ……

                                    ××省××厅
                                  2026年11月25日
```

> 政策性意见通常需要合法性审查、公平竞争审查等程序，起草时提醒用户按厅内流程办理。
