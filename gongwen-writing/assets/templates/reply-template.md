# 批复模板

适用：答复**下级机关**的请示。只对有隶属或业务领导关系的下级使用；对同级部门等不相隶属机关的申请，用复函（见 letter-template.md）。

## 基本结构

```markdown
[发文机关]关于[请示事项]的批复

[来文的下级机关]：

    你单位《关于××的请示》（文号）收悉。经研究，现批复如下：

    一、[明确表态：同意 / 原则同意 / 不同意]
    二、[具体意见和要求]

    此复。

                                    [发文机关]
                                  [成文日期]
```

要点：一文一批，针对请示内容逐项表态；不同意的要说明理由；主送即来文单位。

## 使用示例

```markdown
××省××厅关于××市××局××事项的批复

××市××局：

    你局《关于××的请示》（×财〔2026〕×号）收悉。经研究，现批复如下：

    一、原则同意你局××方案。
    二、请严格按照××规定执行，于××前将实施情况报我厅。

    此复。

                                    ××省××厅
                                  2026年11月25日
```

> 适用前请确认该事项属于本机关对下级机关的审批权限；不在权限内的，不宜以批复答复。
