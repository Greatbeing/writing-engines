# 报告模板

适用：向上级汇报工作、反映情况、答复上级询问。不需批复，**不得夹带请示事项**。上行文须标注签发人。

## 基本结构

```markdown
[发文机关]关于[事由]的报告

[主送机关（一个上级机关）]：

    根据[依据/要求]，现将[事项]有关情况报告如下：

    一、基本情况
    二、主要做法和成效
    三、存在的问题
    四、下一步工作打算

    特此报告。

                                    [发文机关]
                                  [成文日期]
```

## 使用示例

```markdown
××省××厅关于2026年××工作情况的报告

省政府：

    根据省政府工作安排，现将2026年全省××工作情况报告如下：

    一、基本情况
    2026年，全省××（数据由用户提供，不得编造）。

    二、主要做法和成效
    （一）××××。……
    （二）××××。……

    三、存在的问题
    ……

    四、下一步工作打算
    ……

    特此报告。

                                    ××省××厅
                                  2026年11月25日
```

> 如需上级拍板的事项，另行起草请示，不要写进报告“下一步”里请求批准。
