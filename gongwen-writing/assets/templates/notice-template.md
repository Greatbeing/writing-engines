# 通知模板

## 基本结构

```markdown
[发文机关]关于[事由]的通知

[主送机关]：

    [开头：说明背景、依据和目的]，现将有关事项通知如下：

    一、[第一项内容标题]
    [具体内容]

    二、[第二项内容标题]
    [具体内容]

    三、工作要求
    [具体内容]

    [结尾：特此通知 / 执行要求 / 联系方式]

    附件：[附件名称（单个附件不编序号，名称后不加标点）]

                                    [发文机关]
                                  [成文日期]
```

## 使用示例

### 会议通知

```markdown
××省××厅关于召开全省××工作会议的通知

各市、县（区）××局：

    为贯彻落实××部署，总结××工作，安排下一阶段任务，经研究，决定召开全省××工作会议。现将有关事项通知如下：

    一、会议时间
    2026年12月×日（星期×）上午9:00，会期半天。

    二、会议地点
    ××（地址）

    三、参会人员
    各单位分管负责同志和××科（处）负责同志各1名。

    四、有关要求
    1. 请于12月×日前将参会回执报送至××处；
    2. 请参会人员准时参会，原则上不得请假，确需请假的须报经分管负责同志同意。

    联系人：×××，联系电话：××××××××

    附件：参会回执

                                    ××省××厅
                                  2026年11月25日
```

### 工作通知（下达资金）

```markdown
××省××厅关于下达2026年××专项资金的通知

各市、县（区）××局：

    根据××（政策依据），现下达你单位2026年××专项资金（具体金额见附件），并就有关事项通知如下：

    一、资金用途
    ……

    二、管理要求
    （一）及时拨付。请于收到资金后××日内分解下达，不得截留、挤占、挪用。
    （二）绩效管理。……

    三、其他事项
    该资金列××年政府收支分类科目“××”（科目编码以实际为准）。

    附件：2026年××专项资金分配表

                                    ××省××厅
                                  2026年11月25日
```

> 金额、科目编码、时限必须来自用户提供的材料，模板中的××不要自行填充。
