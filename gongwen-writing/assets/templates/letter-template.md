# 函模板

适用：不相隶属机关之间商洽工作、询问和答复问题、请求批准和答复审批事项。同级部门之间、不同系统的机关之间，一般用函。

## 基本结构

```markdown
[发文机关]关于[事由]的函 / 复函

[主送机关]：

    [缘由]，现就有关事项函商（函询/函告）如下：

    一、[事项]
    二、[事项]

    [结语：请予支持 / 盼复 / 特此函达 / 特此函复]

                                    [发文机关]
                                  [成文日期]
    （联系人：×××，联系电话：××××××××）
```

## 使用示例

### 征求意见函

```markdown
××省××厅关于征求《××资金管理办法（征求意见稿）》意见的函

省发展改革委，省教育厅，省科技厅：

    为规范××资金管理，我厅起草了《××资金管理办法（征求意见稿）》。现送你单位征求意见，请于2026年12月×日前将书面意见反馈我厅××处。逾期未反馈的，视为无意见。

    附件：××资金管理办法（征求意见稿）

                                    ××省××厅
                                  2026年11月25日
    （联系人：×××，联系电话：××××××××）
```

### 复函（答复同级部门的申请，不用批复）

```markdown
××省××厅关于××厅申请××经费的复函

省××厅：

    你厅《关于商请安排××经费的函》（豫××函〔2026〕×号）收悉。经研究，现函复如下：

    一、同意从××中安排××经费××万元，用于××。
    二、请严格按照规定用途使用资金，做好绩效管理，自觉接受审计等监督。

    特此函复。

                                    ××省××厅
                                  2026年11月25日
```

> 引用来文时写全标题和文号；文号以来文为准，不要编造。
