# 请示模板

## 基本结构

```markdown
[发文机关]关于[事由]的请示

[主送机关（只写一个上级机关）]：

    [开头：说明请示背景和目的]，现将有关事项请示如下：

    一、基本情况
    [具体内容]

    二、请示事项
    [具体内容]

    三、理由和依据
    [具体内容]

    妥否，请批示。

                                    [发文机关]
                                  [成文日期]
    （联系人：×××，联系电话：××××××××）
```

要点：上行文版头须标注签发人；一文一事；只主送一个上级机关，不抄送下级；附注写联系人和电话。

## 使用示例

### 资金请示（部门向本级政府）

```markdown
××省××厅关于××专项资金预算调整的请示

省政府：

    为保障××工作顺利实施，根据《中华人民共和国预算法》有关规定，我厅拟对××专项资金预算进行调整。现将有关事项请示如下：

    一、基本情况
    2026年省级预算安排××专项资金××万元，截至×月×日已下达××万元。受××因素影响，部分项目实施进度与预算安排不匹配。

    二、请示事项
    拟将××专项资金中××万元调整用于××，调整后总规模不变。

    三、理由和依据
    1. ××项目已具备实施条件，资金需求迫切；
    2. 调整不增加预算支出总额；
    3. 符合××文件关于专项资金统筹使用的规定（文件名称、文号以实际为准）。

    妥否，请批示。

                                    ××省××厅
                                  2026年11月25日
    （联系人：×××，联系电话：××××××××）
```

> 行文关系说明：××厅是省政府组成部门，向省政府请示属于正常上行文。**同级部门之间申请资金或审批事项，应使用“函”而非“请示”**，因为二者不相隶属；答复时用“复函”，不用“批复”。

### 不相隶属机关请求批准：改用函（对照）

```markdown
××省××委关于商请安排××经费的函

××省××厅：

    ……现就有关事项函商如下：
    ……

    请予支持。

                                    ××省××委
                                  2026年11月25日
```
