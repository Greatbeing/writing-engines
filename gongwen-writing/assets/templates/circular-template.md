# 通报模板

适用：表彰先进、批评错误、传达重要精神和告知重要情况。

## 基本结构

```markdown
[发文机关]关于[事由]的通报

[主送机关]：

    [事实概述]，现将有关情况通报如下：

    一、基本情况
    二、存在的问题（或：主要经验）
    三、有关要求

                                    [发文机关]
                                  [成文日期]
```

## 使用示例（情况通报）

```markdown
××省××厅关于2026年××资金绩效评价情况的通报

各市、县（区）××局：

    根据××安排，我厅组织对2026年××资金开展了绩效评价。现将有关情况通报如下：

    一、基本情况
    本次评价覆盖××个地区、××个项目（数据由用户提供）。

    二、存在的问题
    （一）资金拨付不及时。……
    （二）绩效目标设置不科学。……

    三、有关要求
    各地要对照问题清单逐项整改，于××前将整改情况报我厅××处。

                                    ××省××厅
                                  2026年11月25日
```

> 点名批评具体单位或个人前，务必核实事实和口径，并确认是否需要报经厅领导同意。
