# 决定模板

适用：对重要事项作出决策和部署、奖惩有关单位和人员、变更或撤销下级机关不适当的决定事项。

## 基本结构

```markdown
[发文机关]关于[事由]的决定

[主送机关]：

    [决定的缘由和依据]，经[会议/研究]，决定：

    一、[决定事项]
    二、[执行要求]

                                    [发文机关]
                                  [成文日期]
```

## 使用示例（废止文件）

```markdown
××省××厅关于废止部分规范性文件的决定

厅机关各处室、厅属各单位：

    根据××要求，我厅对现行规范性文件进行了全面清理。经厅长办公会议研究，决定废止《××办法》等×件规范性文件（目录见附件），自印发之日起停止执行。

    附件：决定废止的规范性文件目录

                                    ××省××厅
                                  2026年11月25日
```

> 决定类公文权威性强，须经领导集体研究；起草时只写已定的结论，不写尚在讨论的方案。
