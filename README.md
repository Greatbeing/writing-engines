# writing-skills · 写作引擎库

> **不是提示词模板，是文体的操作系统。**

把优秀写作**解构**成可安装、可执行、可评测的 agent skill——每个引擎 = 原子技法 × 风格指纹 × 红线审查，全部从真实代表作蒸馏，经实战文章验证迭代。

## 定位

| 是 | 不是 |
|---|---|
| 文体的解构：怎么选题、怎么开笔、怎么落句 | 风格模仿：学个腔调 |
| 带红线与自检的写作系统 | 一次性 prompt |
| 实战喂出来的活引擎（持续迭代） | 静态范文合集 |

一句话：**模式归纳是尸检，原子操作是手术。** 每个引擎都回答一个问题——这种文体到底是怎么「想」出来的。

## 安装

```bash
# OpenClaw
git clone https://github.com/Greatbeing/writing-skills.git
cp -r writing-skills/human-voice-writing writing-skills/guanfang-writing ~/.openclaw/workspace/skills/
```

目录自包含，无代码依赖，拷贝即用。重启后 `/skills` 即可看到。

## 使用

一句话需求进，一篇文章出。引擎自带触发词：

- **活人感体**：「写公众号文」「写活人感的文字」「城市观察文」「避免 AI 味」「网感文案」
- **官方体**：「写时评」「政论文」「主旋律文章」「浙江宣传体」「体制内爆款写作」

两条内置红线，保证产出不是 AI 腔：

- 活人感体：人物样本必须实名真话，禁止虚构案例；金句只放 ENDING
- 官方体：先确认骨架再填材料；金句 ≤ 3

## 路线图

- [ ] **第三个引擎**——验证「博物馆模式」可复制（特稿体/商业体候选）
- [ ] **AI 味 checker**——把反 AI 味红线做成可执行评分脚本（金句密度/口头检验/破公式检测）
- [ ] **eval/ 双引擎对照评测**——同一主题多引擎同题写作、对照复盘的标准流程
- [ ] **引擎方法论开源**——任何人可按「蒸馏五步」造新引擎

## 方法论：引擎是怎么造出来的

```
选样（10+ 篇代表作）→ 拆解（枚举原子技法）→ 压缩（风格指纹 + 红线）
→ 实战（真实文章验证）→ 反哺（反馈回写技法库）
```

引擎不是「写完就完」，是随每次实战持续迭代的活系统。
