# 人物特稿体 · 处境与变化（v1.0）

> 蒸馏源：《人物》杂志 10 篇代表作（2020-2023）
> 群体（外卖骑手 20-09 / 穷孩子 21-01 / 空难群像 22-03）/ 名人（许渊冲 21-03 / 叶诗文 21-08 / 张颂文 23-02）/ 素人（娜拉 21-05 / 螺丝 21-06 / 家暴母女 23-11）/ 思想回访（潘晓之问 23-10）
> 语料原文：`references/sources/local/`（10 篇，账号已核实）；索引与技法初印象：`references/ref-index.md`

## 核心认知（先于一切技法）

1. **特稿不是写人，是写处境与变化**。读者记住的不是「张颂文是演员」，而是「他用一生的难堪置换来表演质感」。人物是处境的总和——把一个人扔进他的时代、他的职业、他的房间，让他自己说话。
2. **时间是核心变量**。写一个人，就是写他在时间里如何被改变：出走、归来、学会输、等待十年。没有变化的人物是静态雕塑，不是特稿。
3. **记者消失**。情感和信息都由事实与引语承载，记者不评价、不抒情、不总结。克制是特稿最大的力量（写给 132 个遇难者的报道，没有一个「悲恸」的大词）。
4. **细节只服务于处境**。物品、天气、饭菜、职业动作都是处境的一部分；猎奇和堆砌是噪音。
5. **反 AI 味与本体的同一性**：特稿体的克制天然反 AI 腔——AI 越抒情、越总结、越堆抽象词，特稿越是具体、克制、让事实说话。

## 选题引擎：选题四问

写之前，候选人物/群体必须通过四问（至少三问回答「是」或「有」）：

1. **不合身**：这个人身上有没有「不应该」？——履历与活法不符（螺丝：他不该蹲在院子里种花）/身份与处境冲突（刘小样：农村女人不该有思想）
2. **变化**：有没有一个贯穿时间的改变？出走/归来/蛰伏/学会输/重逢——变化越大，特稿越重
3. **现场**：有没有可进入的当下场景？采访对象可访问，现场可观察（院子、水产市场、航班时刻）——没有现场就没有开场帧
4. **时代压强**：时代问题是否压在他身上？系统（外卖）、教育（流动儿童）、性别（娜拉）、灾难（MU5735）——个人故事必须背靠公共议题

选题禁忌：只有名气没有处境（明星八卦）、只有苦难没有变化（感动中国体）、无法访问现场（只能转述）。

## 结构骨架：六块

```
①② 题记装置（可选）+ 开场帧
③ 反差断言/悬念段（主题钩子）
④ 章节化主体（2-5 章，小标题切主题块）
⑤ 双线时间（现在—过去—现在，块内编年）
⑥ 结尾：落回平静当下时刻，留白不总结
```

- **开场帧 ≠ 新闻导语**：绝不用「某某出生于某年，毕业于某校」开头。从一帧具体画面/时刻切入——一个等了十年电话的人、一张订单的送达时间、春天柳絮里种花的手
- 结构原则：**块内编年，块间主题**。时间线被切成主题块（"置换"、"失踪的女人"、"在春天种花才是正经事"），每块内部才按时间走
- 结尾法则：不升华、不总结、不点题——落回一个平静的当下（刘小样最后在院子里安顿），让读者自己感受重量

## 十原子技法

| # | 原子 | 操作 | 语料例证 |
|---|------|------|---------|
| A1 | **开场帧** | 用一帧具体画面/时刻开场，读者直接进现场 | 张越等了十年的电话；航班时刻「3月21日，昆明天气晴」 |
| A2 | **题记装置** | 一句文学引语定调（鲁迅/诗句），再转入人物 | 「然而娜拉既然醒了……只得走」 |
| A3 | **引语载荷** | 情绪与信息用直接引语承载；关键引语极短、极口语；引语附身体细节（咬咬牙/愣了一下） | 「我宁可痛苦，我不要麻木」 |
| A4 | **细节处境化** | 物品/天气/职业动作进入处境；细节有出处，不凭空造 | 种花的手糙到指纹解锁失败 |
| A5 | **履历压缩** | 一段式人生：10岁半选拔进京…20岁毕业…25岁离职…此后近30年同一行；用简历的节奏写人生 | 螺丝的履历段 |
| A6 | **反差断言** | 开头断言一个「不常见/不应该」，制造张力 | 「他的活法是北漂生活的一种不常见答案」 |
| A7 | **群像切片** | 事件群像：一人一场景一段生平，个体叙事拼出事件的重量 | MU5735 的 132 人 |
| A8 | **克制抒情** | 痛苦与感动全靠事实压强；禁用抒情大词（悲恸/伟大/泪目/震撼） | 全篇没有一个抒情形容词 |
| A9 | **章节标题** | 名词/比喻短语，克制有诗意不剧透 | 《置换》《失踪的女人》 |
| A10 | **参考资料** | 调查类文末列文献清单；正文用细节转述研究，不用术语 | 外卖骑手的学术文献列表 |

## 四种模式组合规则

| 模式 | 适用 | 标准组合 |
|------|------|---------|
| **名人类** | 演员/运动员/学者等公众人物 | 热点钩子(现时热度数据) → 细节清单(微博/生活细节) → 反差断言 → 双线(爆红×蛰伏) → 结尾当下时刻 |
| **素人类** | 普通人/边缘人 | 反差断言开场 → 场景帧 → 履历压缩 → 活法/处境展开(引语) → 章节推进时间 → 结尾安顿 |
| **群体调查类** | 系统性议题 | 个体场景帧 → 机制拆解(细节转述研究) → 多个体切片 → 呼应开头 → 参考资料清单 |
| **事件群像类** | 灾难/公共事件 | 时间帧(精确时刻) → 一个接一个具体的人 → 平静收束(不总结，不升华) |

## 标题公式

`人名/群体 + 比喻性断言或处境短语`：克制、有诗意、不剧透。

- 《螺丝不肯拧紧》《与平庸作战》《困在系统里》《漫长的重逢》《东京不见叶诗文》

禁忌：写实报告式标题（《对X的深度调查》）、情绪化标题（《泪目！》）、结论式标题（《他终于成功了》）。

## 红线审查（写作完成后逐条过）

1. **引语必须真实**：被访者说的话不得美化、润色、虚构——这是伦理红线，也是风格红线（真实的口语比修饰的书面语有力十倍）
2. **细节必须有出处**：采访所得/现场观察/文献转述——凭空造细节 = 造假
3. **零抒情大词**：悲恸/伟大/震撼/泪目/感人/励志 一律禁用；情绪靠事实压强
4. **记者不评论**：不写「这令人深思」「这体现了」——让读者自己得出结论
5. **禁总结结尾**：结尾点题、升华、给答案 = 降维；留白是尊重
6. **禁 AI 腔**：跑 `tools/ai-flavor-checker.py`，总分 ≤ 30 才算过（特稿天然应在此区间）

## 工作流

```
选题四问 → 素材采集（现场/采访/文献，要求真实）→ 骨架确认（六块+章节标题）
→ 填材料（原子技法）→ 标题工程（公式）→ 红线审查 → checker 评分
```

素材不足时不要硬写：特稿的底线是真实。没有采访与现场，只有二手转述 → 换选题或换引擎（转述内容用三联体/官方体是合规选择）。
