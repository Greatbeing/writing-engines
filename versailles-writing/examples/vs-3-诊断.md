# 一条朋友圈的凡尔赛诊断

**原文**

> 好烦，公司年会又抽中了一等奖，家里已经有两台一样的了，不知道送给谁。去年那台还没拆封呢。有没有人教教我怎么婉拒？

**核心炫点**：运气好、家里条件好（直白版：“我又中了大奖，而且我根本不缺”）。

**原子定位**

| 位置 | 原子 | 说明 |
|---|---|---|
| “好烦” | 困扰包装 | 把中奖写成烦恼，开场定调 |
| “又抽中了一等奖” | 不经意带出 | “又”字暗示不是第一次 |
| “家里已经有两台” | 抱怨式炫耀 | 抱怨的是东西太多 |
| “去年那台还没拆封” | 数字轻描 | 用“还没拆封”轻描已有的财物 |
| “有没有人教教我怎么婉拒” | 反问求助 | 求助本身就是炫耀，没人真能回答 |

**凡度**：4 / 5。包装完整、只炫一样、不点破；扣一分是“两台”“去年那台”有点堆，可以删掉其中一个。

**直白翻译**：我年会中了一等奖，这种奖品我家已经不缺了。

**改到 5 分的写法**：删掉“去年那台还没拆封”，把“不知道送给谁”换成“我妈说再拿回来她就要扔了”——让别人替你说出“太多了”。
