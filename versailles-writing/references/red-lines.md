# 红线与常见翻车

## 红线（命中即重写）

每条都给出改法：把“禁止”去掉，剩下的话仍能指导写作。

1. **点名真人**：仿写某位网友、明星的真实帖子。→ 人物全部虚构，身份泛化（“我老公”“同事”）。
2. **真带货**：写出品牌全称、型号、价格、购买链接。→ 用颜色、简称、形状代替品牌。
3. **直接自夸**：“我真的太优秀了”。→ 把夸奖换给别人说，或藏进抱怨里。
4. **炫点堆叠**：一段里同时晒房、车、学历、老公。→ 只留一样，其余删。
5. **自己拆包**：结尾“哈哈开玩笑的”“我是不是很凡尔赛”。→ 停在一声叹气或一个提问上。
6. **羞辱读者**：“你们这种人不懂”。→ 降维只拿自己开刀，不贬低读者。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 真自嘲 | 放低之后没有抬高 | 给“不行”加一个离谱的高标准 |
| 炫富广告 | 价格、品牌全称 | 删价格，品牌换成颜色或简称 |
| 太长 | 超过 600 字，像小作文 | 砍到一个场景、一个炫点 |
| 语气太亢奋 | 感叹号、表情连发 | 换成“唉”“好烦”“算了” |
| 炫点当主语 | “我买了 XX” | 把 XX 移进从句或别人嘴里 |
| 读不出来 | 包得太深，没人看出炫点 | 核心名词至少出现一次 |
