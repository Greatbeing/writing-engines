# 蒸馏来源与原子映射

**来源与核对说明**

- 「凡尔赛文学」2020 年前后在微博、豆瓣成为热门话题，名称借自日本漫画《凡尔赛玫瑰》所写的法国宫廷。以上背景为常见说法，**来源与时间未逐条核对**。
- 本引擎只收句式拆解结论；**不收、不引用任何具体网友原帖**，不点名任何真实账号或公众人物。
- 下表为对常见句式的归纳，不是对某篇文本的拆解。

| 常见句式 | 主要原子 |
|---|---|
| “在某地开会/出差，顺便……” | 1 不经意带出 |
| “房子太大/车太宽，好麻烦” | 2 抱怨式炫耀、7 困扰包装 |
| “只考了……，被嘲笑了” | 3 自谦实捧、6 数字轻描 |
| “店员/同事非说我……” | 4 他人代夸 |
| “又寄来一个橙色盒子” | 5 名物轻放 |

| “第一次知道……原来要……” | 9 降维对比 |
| “唉，算了，睡了” | 10 淡收 |
