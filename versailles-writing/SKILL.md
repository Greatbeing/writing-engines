# 凡尔赛体——认知引擎版

> 凡尔赛的好，不在晒了什么，在晒得像没晒：炫耀藏在抱怨里，得意藏在烦恼里，读者自己把它挖出来，才会笑。
> 蒸馏源：2020 年前后微博、豆瓣「凡尔赛文学」话题下的公开帖与网友仿写，及其后的段子、短视频文案。
> 篇目与原子映射见 `references/sources.md`。只收拆解结论，不收具体网友原帖。

## 能力边界

**能做**：写出让人一眼看穿又忍不住笑的凡尔赛文本；给一段文字做“凡尔赛诊断”；把凡尔赛翻译成直白话。

**不能做**：

- **点名真人。** 不仿写、不嘲讽具体网友或公众人物的真实帖子；人物一律虚构。
- **写真炫富。** 不为真实品牌、楼盘、产品写软广；品牌名只作泛化道具。
- **写成真自嘲。** “我”放低是假的，底下一定藏着抬高；真放低就跑题了。
- **伪造数据。** 涉及收入、学校、职位等，素材没给就虚构并注明“综合创作”。

**盲区**：长文叙事撑不住，800 字以上会腻；口语化之外的正式场合不适用。

## 核心认知

1. **炫耀必须被包起来。** 包装纸是抱怨、困扰、谦虚、求助；直接说出来就只是炫富。
2. **信息要“不经意”。** 关键的那个名词（学校、车、职位、数字）放在从句、括号或别人嘴里，像顺手带出。
3. **反差是笑点。** 语气越委屈、越平淡，炫的东西越大，越好笑。
4. **读者负责拆包。** 作者不点破，不说“我好厉害”；拆包的快感留给读者。
5. **一次只炫一样。** 堆三样东西就成了清单，反而不像凡尔赛。

## 原子

10 个原子。定义、典型用法、原创示范、常见错误见 `references/atom-ops.md`。

| # | 原子 | 动作 |
|---|---|---|
| 1 | 不经意带出 | 把要炫的名词放进从句或括号里，主句讲别的 |
| 2 | 抱怨式炫耀 | 抱怨的对象恰好是好东西（太大、太多、太快） |
| 3 | 自谦实捧 | 先说自己不行，“不行”的标准高得离谱 |
| 4 | 他人代夸 | 借别人的话（老公、同事、店员）说出夸奖 |
| 5 | 名物轻放 | 品牌、学校、地名只说半个或用简称，像很熟 |
| 6 | 数字轻描 | 大数字配小语气（“才”“也就”“随便”） |
| 7 | 困扰包装 | 把优越条件写成需要解决的烦恼 |
| 8 | 反问求助 | 结尾问一句“姐妹们怎么办”，其实不需要答案 |
| 9 | 降维对比 | 拿普通人的标准自比，显得自己“不懂” |
| 10 | 淡收 | 收在一个疲惫或无奈的表情、一句叹气上 |

## 组合规则

```
文本 = 起(不经意带出 / 困扰包装) + 行(抱怨式炫耀 / 自谦实捧 / 他人代夸 / 名物轻放 / 数字轻描) + 收(反问求助 / 淡收)
```

**一篇 3–5 个原子；要炫的东西只有一样；不经意带出或名物轻放至少一处；收尾不点破。**

## 风格指纹（写完逐项核对，两项不过就重写）

1. **一个核心炫点**：全文能用一句话说出“他到底在炫什么”。
2. **语气词压场**：“唉”“好烦”“真的不懂”“也就”“才”等降调词 ≥ 3 处。
3. **无直接自夸**：不出现“我很厉害/很有钱/很优秀”。
4. **炫点藏位**：核心名词出现在从句、括号、引语里，不作主语。
5. **短**：朋友圈体 ≤ 200 字；段子体 ≤ 600 字。
6. **不点破**：结尾不解释、不“开个玩笑”。

## 红线（写作规则）
- 人物虚构，不对应任何真实网友或公众人物。
- 品牌写泛称或简称（“那个蓝色盒子”“某 A 字头”），不写型号与价格链接。
- 放低只是包装，底下必须有一样被抬高的东西。
- 只炫一样：其余细节都为这一样服务。
- 诊断时先指出炫点，再标出每个原子的位置，最后给“凡度”（1–5）。
- 红线与常见翻车见 `references/red-lines.md`。

## 工作流程

1. 问清用途：玩梗、讽刺、诊断还是翻译（不清楚只问一句）。
2. 定一个核心炫点，写成一句直白话（“我老公送了我一辆车”）。
3. 选包装纸：抱怨、困扰、谦虚、求助选一种为主。
4. 选 3–5 个原子，先写一行原子链。
5. 成稿，删掉一切直接夸自己的句子。
6. 对照风格指纹自检，跑 `tools/ai-flavor-checker.py --engine versailles-writing`，报告过与不过。
