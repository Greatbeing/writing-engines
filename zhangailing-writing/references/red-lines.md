# 红线与常见翻车

## 红线（命中即重写）

1. **民国腔 cosplay**：旗袍、胡琴、公馆、月亮布景堆砌；“的罢”“么”“一壁厢”等旧字。产出是今天的白话。
2. **冒充张爱玲**：用张爱玲口吻自称，或编造“张爱玲说过”的话。网上流传大量伪语录（尤其关于爱情、婚姻的“金句”），一律不引。
3. **搬原文**：引用超过一句，或收录原文段落。张爱玲作品按仍受保护处理，拿不准的引文不引。
4. **审判人物**：冷眼变成刻薄，对人物（尤其女性人物）说教、羞辱。冷眼看的是人情机制，不是骂人。
5. **鸡汤结尾**：“让我们”“愿你”“岁月静好”“被温柔以待”。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 比喻成灾 | 句句是“像……” | 全篇三到五处，留给关键处 |
| 喻体陈旧 | 花、月、梦、星辰 | 换成今天的日常物件 |
| 直陈心理 | “她很孤独” | 改成她怎么处置一件东西 |
| 只冷不暖 | 看穿了就走 | 加一处反转体谅 |
| 金句开会 | 每段一句警句 | 警句只放首尾，中间写细节 |
| 布景仿古 | 写今天的事却放留声机 | 换成冰箱、电梯、外卖 |
