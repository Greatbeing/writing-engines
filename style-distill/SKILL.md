# 风格蒸馏

把「我喜欢这个人的文字」拆成「他具体做了哪几个动作，我怎么练」。

## 能力边界

- 能做：从 ≥3 篇同一作者的文章里，拆出可模仿的**动作**，每个都有原文证据。
- 不能做：只给 1–2 篇时**不出结论**，只说「再给一篇才能交叉验证」，可以先做单篇观察，明确标「单篇」。
- 不能做：看不出作者**绝不做**什么。红线只能由懂这个文体的人补。
- 不凭印象：只依据用户贴的文本；对作者的既有名声、评论家说法一律不用。
- 版权：例句每条 ≤30 字，产物里不复述整段原文。

## 核心认知

1. 风格是**动作**，不是形容词。「语言质朴」不可学；「先写手上的活，最后才写人的心情」可学。
2. 一个动作出现在 ≥2 篇里才算这位作者的，只见于一篇的可能是那篇的题材。
3. 拆出来的多数动作，别的作者也在用。值钱的是**组合**和少数独有的那几个。
4. 成品里看不见作者动笔前、交稿后的动作（选材、自查）。这类不要硬猜。

## 原子

一个原子 = 名称（4–8 字，动词开头）＋ 一句话做法 ＋ 触发条件 ＋ 证据。

| 要求 | 合格 | 不合格 |
|---|---|---|
| 是动作 | 先说价钱，再说人 | 文字有温度 |
| 可检查 | 每段末句不超过 10 字 | 节奏感强 |
| 有证据 | A02「……」A05「……」 | 他常这样写 |

**证据规则（硬）**：每个原子列出「篇号＋原文片段（≤30 字，逐字摘）」。**支持篇数 = 列出的不同篇号数**，不是你的估计。<2 篇的放进「单篇观察」，不进主表。

归族：对照 `references/families.md` 的 18 个族，能归就归，并写出库里同动作的已有原子名；都不像才标「独有」。

## 组合规则

先编号文章（A01、A02…），再按顺序：逐篇抽 4–8 个候选 → 跨篇并成同一动作 → 数篇号 → 归族 → 排序（支持篇数多的在前，独有的标出）。并簇时名字不同、动作相同也要并；只是风格形容的直接丢。

## 风格指纹

给 3–5 条**可数**的指标，阈值写区间，并说明你是怎么数的：平均句长、短句占比、段落长度、某类标点每千字次数、开头首句长度等。数不准就说「估」，不编小数点。

## 红线

- 不编证据 → 摘不到原文就删掉这个原子。
- 不凑数 → 宁可只拆出 4 个，也不拿形容词充数。
- 不吹作者 → 不写「大师」「炉火纯青」，只写动作。
- 不贴大段原文 → 例句 ≤30 字。
- 不替用户写整篇 → 练习只给题目和要求，写由用户写。

## 工作流

1. **收语料**：确认篇数和是否同一作者；<3 篇先说明限制。完成：每篇有编号和标题。
2. **拆**：按组合规则走完。完成：主表每行支持篇数 ≥2，证据可在原文里找到。
3. **出学习版**（默认），格式见 `references/learn-template.md`。完成：每个原子都配一道练习。
4. **问一句**：「要不要整理成引擎草稿提交到采风？」用户说要，才出**贡献版**，格式见 `references/contribute-template.md`，并列出入库前人要做的四件事。
5. **用户交回练习时**：只点评用到了哪个原子、哪句最像、哪句最该改，不重写全文。
