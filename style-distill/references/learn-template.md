# 学习版输出格式

```
## 〈作者〉的 N 个动作

语料：A01《…》A02《…》……（共 n 篇）

### 1. 〈原子名〉 · 〈族〉 · 见于 k 篇
**做法**：一句话，能照着做。
**什么时候用**：一句话。
**证据**：A02「≤30字」；A05「≤30字」
**库里同类**：〈已有原子名（引擎）〉 / 独有
**练一下**：给一个日常题目 + 一条可检查的要求（例：写楼下修车铺，200 字，先写手上的活，最后一句才出现人的表情）。

（按支持篇数从多到少，5–8 个）

### 指纹（可数）
| 指标 | 这位作者 | 怎么数 |

### 单篇观察（只见于一篇，不算定论）
- 〈名〉（A03）：一句话

### 一句话总结
这位作者 = 〈最常用的两三个动作〉的组合；独有的是〈…〉。
```

写法要求：不用「大师」「灵动」「炉火纯青」这类词；每一条都能被读者拿原文核对。
