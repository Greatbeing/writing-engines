# 练习三 · 组合（4 题）

> 单原子过关之后，练顺序与密度。每题给定三个族、一个场景、300 字。
> 要求不是「三族都出现」——那是及格线；要求是**三族各司其职，顺序说得清理由**。
>
> 先排顺序，再动笔。写完之后，对照每题的「答案要点」检查三处：
> 第一族落在哪一句、第二族用了几次、第三族有没有越位。

## 总则

1. **字数按 280–340 字算**（去空白字符数，含标点），低于 280 字通常有一族没写透。
2. **每题写完后标链**：在第几句用了哪一族。标不出来，说明是碰巧撞上的。
3. **不许换族。** 三族是给定的；写不动的时候，换场景细节，不换族。

---

## 练习一

**组合**：小处起笔 → 数据压舱 → 不收的收尾

**场景**：写一次搬家。

**三族的任务**：
- 小处起笔：开头从一个具体的小东西进入（一把钥匙、一个纸箱、一卷胶带）。
- 数据压舱：中段用数字承重（搬了几趟、住了几年、多少平米、扔了多少袋）。
- 不收的收尾：结尾停在一个动作或画面上，不总结。

**建议顺序**：小处（第 1–2 句）→ 数据（中段，至少 3 个数字）→ 收尾（最后一句）。

**答案要点**：
1. 首句应是一个可指认的物或场景，且 ≤25 字；如果首句是「搬家是一件麻烦的事」，
   小处起笔没做到。
2. 数字不能只出现在开头。合格的样子是：数字出现在你本来要写「东西太多了」的地方，
   用「三年，四个纸箱，两趟车」代替「东西太多了」。
3. 末句不能出现「终于」「新的开始」「明白了」这类总结词；合格的样子是
   「钥匙交出去的时候，还是热的」这类动作或画面。

**判定表**：

| 检查项 | 合格 | 不合格 |
|---|---|---|
| 第一族位置 | 首句就是一个具体的物/场景，≤25 字 | 首句是判断或抒情 |
| 第二族密度 | 3 个以上带单位数字，且至少 2 个出现在中段之后 | 数字堆在开头，后文全是感受 |
| 第三族形态 | 末句 ≤25 字、有动作、无总结词 | 末句是「我明白了……」 |

## 练习二

**组合**：预设驳论 → 比喻 → 金句断语

**场景**：写「短视频让人变笨」这个说法。

**三族的任务**：
- 预设驳论：先把「不能这么说，短视频也学到东西」这一类反方说全，承认一半，再回答。
- 比喻：用一个日常物件照亮你的判断（例如把信息比成食物、把注意力比成容器）。
- 金句断语：全文只留一句断语，放在回答之后、结尾之前。

**建议顺序**：预设驳论（前 40%，引述 + 承认）→ 比喻（中段，一次）→ 金句断语（后段，一次）。

**答案要点**：
1. 反方至少 2 句，且要用到「有人会说」这类引述；反方说完之前不能出现转折。
2. 承认句必须落地（「这话有一半道理」），不能是「虽然……但是……」的空转。
3. 比喻只能出现一次；出现第二次，就从「照亮」变成「装饰」。
4. 断语 ≤34 字，能脱离上下文独立读通；前后各有至少 2 句具体内容。

**判定表**：

| 检查项 | 合格 | 不合格 |
|---|---|---|
| 驳论结构 | 先引 ≥2 句，再承认，再回答；反方关键词在回答里再现 | 直接反驳；或承认完就换题 |
| 比喻数量 | 全文 1 处，且是具体物 | 2 处以上；或是抽象类比 |
| 断语位置 | 1 处，在回答之后、结尾之前 | 开头一句 + 结尾一句，两处打架 |

## 练习三

**组合**：冷笔白描 → 回环呼应 → 自嘲

**场景**：写一次通勤。

**三族的任务**：
- 冷笔白描：全程不写情绪形容词，只写动作、时间、数字、物。
- 回环呼应：开头出现的一个词或物，在结尾再出现一次，意思比第一次多一点。
- 自嘲：中途把自己放低一次（承认自己也麻木、也偷懒、也算计过）。

**建议顺序**：白描（贯穿全篇）→ 回环（首尾各一次）→ 自嘲（中后段，一次）。

**答案要点**：
1. 自嘲只有 1–2 处，多了变成自怜；合格的样子是「我也没下车，我也在看手机」。
2. 回环的那个词必须在首尾都出现，且第二次要落在新语境里；
   如果首尾同一句话照抄，那是重复，不是回环。
3. 白描是底子，不是一段。若中段突然出现「我心里很累」，前面的冷笔就白写了。

**判定表**：

| 检查项 | 合格 | 不合格 |
|---|---|---|
| 白描纯度 | 零情绪形容词；≥3 个动作动词 | 中段出现「心里很累」类句子 |
| 回环 | 同一个词/物在首尾各现一次，含义有变化 | 首尾照抄同一句；或只有开头出现 |
| 自嘲 | 1–2 处，与「我」同句 | 3 处以上；或自嘲变成自我表扬 |

## 练习四

**组合**：分类拆解 → 正经夸张 → 号召落点

**场景**：写「公司的周会」。

**三族的任务**：
- 分类拆解：按一个标准把周会拆成互斥的几类（例如按目的分、按主持人分）。
- 正经夸张：用「假如……那么」推演其中一类，推到荒唐处，不自己评价。
- 号召落点：结尾给出一个可做的动作（不必宏大，具体即可）。

**建议顺序**：分类（前段，给出「第一……第二……」）→ 夸张（中段，只推一类）→
号召（末句，一个动作）。

**答案要点**：
1. 分类标准要写在明处（「按目的分」），条目互斥；如果两类可以同时成立，说明标准没定好。
2. 夸张只推一类，不要三类都推；推演出「假如周会的目的只是留痕，那么最有效率的开法
   是不开会」这类有终点的结论。
3. 号召落点要具体到动作：「下次开会前，先问一句这次要留下什么」；
   写成「让我们一起努力」不算。

**判定表**：

| 检查项 | 合格 | 不合格 |
|---|---|---|
| 分类 | 标准明确，条目 ≥2 且互斥 | 条目重叠；或只是罗列现象 |
| 夸张 | 推演链 ≥2 处，有终点，无评价词 | 推一半自己先笑；或只夸张不推 |
| 号召 | 末句是可执行的动作 | 「让我们」「希望大家」类空号召 |

## 做完之后

四题写完，你会有一份自己的「原子链」样本。把它和
`renminribao-writing/examples/rmrb-1-工匠精神.md` 稿尾自标的原子链比一比：

> 高位定调 → 时空坐标 → 历史纵深 → 以小见大 → 数据并举 → 四字格凝练
> → 排比递进 → 辩证回应 → 对仗收束 → 号召落点

你的链比他短，这不重要。重要的是：**你的每一步都说得出为什么**。
说不出的那一步，就是下一轮要回到 [02 仿写](02-练习-仿写.md) 单独练的族。

最后，把自己的定稿跑一遍诊断：

```bash
python tools/diagnose.py 我的稿子.md
```

诊断给出的「最缺三族」如果和你写链时的感觉一致，说明你已经能自己判自己了。
