# 教学层 · 从认原子到找自己

> 仓库里已经有 17 个引擎、182 个原子（18 个族，另有 63 个独有），缺的是「人怎么学会」。
> 这一层只做一件事：把「风格」拆成可练的动作，再把动作拼回一个人的样子。

## 先看三个数

| 数 | 是什么 | 出处 |
|---|---|---|
| **182** | 已标族、汇入总库的原子 | `atoms/index.json` |
| **18** | 跨引擎共用的族（「独有」不算族） | 同上；`atoms/LIBRARY.md` 按 18 族列，独有单列 |
| **63** | 只在一个引擎里出现、且没有共名的原子 | 同上 |

17 个引擎全部有原子表并已入库，包括 `feature-writing`（人物特稿）与
`gongwen-writing`（公文）。本层教的不是「17 个引擎」，
是「17 个引擎里被反复使用的 18 个动作」。

一句话，也就是整套材料的前提：

> **不同作者 = 同一批原子的不同选择、顺序与密度。**

这句话在 `README.md` 与 `atoms/LIBRARY.md` 里都写过。本层负责把它变成
可以练、可以判、可以复测的步骤。

## 三条线

| 线 | 要回答的问题 | 材料 | 单步时间 | 做完手里有什么 |
|---|---|---|---|---|
| ① 认原子 | 这一句在做什么动作？ | [00 讲义](00-风格是组合.md) + [01 认原子](01-练习-认原子.md)（12 题） | 读讲义 30 分钟；每题 6–8 分钟，合计约 2 小时 | 一张 12 题答案纸：每题写「族名 + 证据 + 另一种可能」 |
| ② 看组合 | 同一族，为什么两个人写出来不一样？ | 00 讲义的三组对照 + [03 组合](03-练习-组合.md)（4 题） | 读对照 30 分钟；每题 40–60 分钟，合计约 4 小时 | 4 篇 300 字，每篇标出三族的先后与各出现几次 |
| ③ 找自己 | 我的稿子像谁，缺哪三族？ | [`tools/diagnose.py`](../tools/diagnose.py) + [02 仿写](02-练习-仿写.md)（8 题） | 诊断 10 分钟；每题 20–30 分钟，合计约 3.5 小时 | 一份诊断报告 + 8 段 100 字 + 下一轮要补的三族 |

推荐顺序是 ① → ② → ③，但不必等。手里有稿子的人，可以直接从 ③ 开始：
先诊断，再只练它指出的三个族，改完复测。两条路线的时间不同：

- **系统路线**：约 10 小时，分两周。先认全 18 族，再看组合，最后诊断自己。
- **急诊路线**：约 2 小时。诊断 → 挑三个缺族各写 100 字 → 改稿 → 复测。

## 每一步的过关标准

判标准必须能被别人复核，否则只是自我感觉。

| 步骤 | 过关线 | 不过线的典型样子 |
|---|---|---|
| 认原子 | 说得出族名；在原文里指得出证据（词、句、位置）；能说出「也可能是另一族」的理由 | 只答「有画面感」「很真实」——这不是族名 |
| 单原子仿写 | 三条合格标准全部可勾（02 每题都给了三条） | 三条里过了两条，剩下一条靠「我觉得还行」 |
| 组合 | 三族都出现；顺序说得清为什么；不少于 280 字 | 三族挤在开头，后文回到默认腔调 |
| 诊断 | 三个缺族各写 100 字后复测：命中数上升，或证据从「无」变成「有」 | 只盯着分数涨没涨，不看证据 |

## 怎么跑

```bash
# 诊断自己的稿子（只看命中了哪些族、缺哪三族）
python tools/diagnose.py 稿子.md

# 同时给一份指定引擎的 checker 分（引擎名见下一条命令）
python tools/diagnose.py --engine luxun-writing 稿子.md

# checker 支持哪些引擎
python tools/ai-flavor-checker.py --list-engines

# 改完再看一眼 AI 腔指标
python tools/ai-flavor-checker.py 稿子.md
```

诊断输出里每一族都带「依据 + 证据」，可以逐条反驳。它给的是
**启发式估计，不是人工判断**；分数只说明「文本里有没有这个动作」，
不说明「这个动作用得好不好」，更不说明「你像哪位作者」。

## 这套材料不做什么

- **不引受版权保护的原文。** 所有练习材料来自本仓库 `examples/` 的引擎试写稿
  （MIT，`LICENSE` / `NOTICE.md`），每题标了文件路径。讲义里的引文每处不超过 30 字，
  且只引这些试写稿。
- **不冒充文学理论。** 族是从 17 份原子表里归纳出的工程分类，不是学院派的文体学。
  它有明确的数据口径（见 00 讲义第六节），也有明确覆盖不到的地方。
- **不教 63 个独有。** 独有是签名，不是地基：先把 18 个共用族练到能认、能写，
  再谈个人标记。独有集中在文种流程（公文 9/9、特稿 7/10）、小说叙事（金庸 7/10）
  与语言质地（阿城、汪曾祺、张爱玲各 5/10），需要文种规则、长篇结构或长期语感承载，
  不适合作为第一课。
- **不承诺「学完就像谁」。** 这套材料能给的是：认出动作、写出动作、看见自己的缺口。
  像不像某位作者，得由读者判断，不由工具判断。

## 从这里开始

第一次来，按这个顺序读：

1. [00 讲义](00-风格是组合.md) 第一、二节：先知道 18 族与独有是什么，再知道「组合」指哪四件事。
2. [01 认原子](01-练习-认原子.md) 第 1–4 题：材料短，答案清楚，先建立「族名 + 证据」的答法。
3. 用自己的稿子跑一次 `python tools/diagnose.py 稿子.md`。
4. 按诊断给的三个缺族，去 [02 仿写](02-练习-仿写.md) 找对应题；没有对应题的族，
   去 [03 组合](03-练习-组合.md) 或 01 的对应题里找例子。
