# 00 · 风格是组合

> 这份讲义只回答一个问题：**为什么说「作者 = 原子的选择与密度」？**
> 族与原子数来自 `atoms/index.json`；对照二里的文本计数口径见第六节。
> 所有引文来自本仓库 `examples/` 的引擎试写稿，每处不超过 30 字，并标明路径。

这张表先说明三件事。

**第一，覆盖面差别很大。** 「小处起笔」8 个原子铺在 8 个引擎上，几乎人人都有；
「分类拆解」只有 3 个原子、2 个引擎，「号召落点」只有 2 个原子、2 个引擎。
族内原子越多，变体越多，越容易长出自己的写法；族内原子少，动作更单一，
学起来反而快——一次就学完，没有多少分岔。

**第二，同族不同名。** 「小处起笔」这一族，在八个引擎里分别叫：小处切入（鲁迅）、
观察切口（脱口秀）、亲历小事起笔（王小波）、即事起兴（苏轼）、闲闲起笔（汪曾祺）、
场景钩/故事钩（官方）、以小见大（人民日报）、场景微电影（活人感）。
名字不同，动作相同：从一个极小、具体、人人见过的东西切入，让大题目先有落脚点。
`atoms/LIBRARY.md` 在每个族的开头写了「通用定义」，在各引擎的原子文件里写「变体差异」。
学的时候先认通用定义，再认变体——否则会把八个名字当成八种技法。

**第三，族是归纳出来的，不是先验的。** `atoms/LIBRARY.md` 末尾记了对初拟 14 族的
七条调整及理由（例如把「金句收束」改名为「金句断语」，因为它在开头、段中、结尾都有）。
这是工程分类，不是文学理论；它有用，是因为能指导练习，不是因为它「正确」。

## 二、「组合」到底指哪四件事

说「作者是组合」，容易滑成一句空话。拆开看，组合只有四个可操作的变量：

1. **选哪些族。** 一篇稿子不必 18 族都用。鲁迅的《论「收到」》
   （`luxun-writing/examples/lx-1-收到.md`）用了小处起笔、正经夸张、命名、典型画像、
   预设驳论、金句断语、古今对照、自嘲、不收的收尾、冷笔白描——十族左右；
   它没有用排比，也没有用号召落点。缺哪几族，本身就是风格。
2. **先哪个后哪个。** 同是小处起笔，下一步可以接正话反说，也可以接换层级。
   顺序不同，读者被带的路径就不同（第三节的三组对照全在讲这件事）。
3. **每千字几处。** 一个族用一次是提醒，用五次是腔调。
   `atoms/LIBRARY.md` 在每个族下都标了密度区间，例如「自嘲」普遍 1–2 处，
   「金句断语」在官方体 ≤3 处、在张爱玲首尾各一。
4. **用哪个变体。** 「预设驳论」在鲁迅是「引其言而驳」，在毛选是「承认后答、两点论」，
   在苏轼是「主客问答」。动作相同，语气与结构不同。

把这四个变量写下来，一篇稿子的「风格」就不再是形容词，而是一张可核对的表：
选了哪几族、什么顺序、各几次、用的哪个变体。练习二（单原子）练第 1、4 项，
练习三（组合）练第 1–3 项，诊断工具估第 1、3 项。

## 三、三组真实对照

下面三组对照，每组两人用同一族，但下一步、密度或结构不同。
引文全部来自本仓库 `examples/` 的引擎试写稿（MIT），每处不超过 30 字；
它们是「按某位作者的技法写的习作」，不是作者原文，引用只为对照动作，不做文本考证。

### 对照一：都从「小处」起笔，下一步不同

鲁迅一侧取自 `luxun-writing/examples/lx-1-收到.md`（《论「收到」》），
苏轼一侧取自 `sushi-writing/examples/ss-1-加班遇雪.md`（《加班遇雪》）。
两人都在第一句放了一个极小的东西，但第二句开始分道。

| 鲁迅（lx-1） | 苏轼（ss-1） |
|---|---|
| 起点：「单位的工作群里，近来流行一句话：“收到。”」 | 起点：「十二月四号，周五，改完最后一版方案是凌晨一点二十。」 |
| 这一小处是什么：一句群消息，物件是「话」 | 这一小处是什么：一个时间戳，物件是「钟点」 |
| 下一步：正话反说。「这真是一种了不起的效率。」把小事往荒唐处推 | 下一步：换层级。「要是按今天算……按一辈子算」，把事放回尺度里 |
| 全文落点：揭底一句，「不是回复，是表态」 | 全文落点：转念，「都是给这场雪买的门票」 |
| 族内原子：小处切入 1/10；正经夸张、金句断语各 1/10 | 族内原子：即事起兴 1/10；换层级、自嘲各 2/10 |
| 读完的感觉：被指认，然后发冷 | 读完的感觉：被安慰，然后松一口气 |

同一族、同一位置、同一「小」，差别全在**第二步**：一个向下揭，一个向上拉。
这就是组合的第一个变量在实际文本里的样子。

### 对照二：都用「冷笔白描」，冷的来源与密度不同

余华一侧取自 `yuhua-writing/examples/yh-1-三个西瓜.md`，
李娟一侧取自 `lijuan-writing/examples/lj-1-阳台菜地.md`。
两人都不写「我很伤心」，但一个让冷笔承重，一个让冷笔铺满。

| 余华（yh-1） | 李娟（lj-1） |
|---|---|
| 冷笔在原子表里的位置：零度叙述、死亡轻写，2/10 | 冷笔在原子表里的位置：琐事铺满、风物白描、家人喜剧，3/10 |
| 冷的来源：把最重的事压到最短的句子里 | 冷的来源：把最轻的事写得又准又长 |
| 数字与账目词：40 处（约 32.8/千字） | 数字与账目词：12 处（约 12.1/千字） |
| 数字在干什么：当账算。「八块。」「够买十六斤米。」 | 数字在干什么：当物证。「数了两遍，都是十九。」 |
| 一句证据：「小军已经躺在一个铁柜子里了。」 | 一句证据：「她一棵都舍不得拔。」 |
| 读者被什么打动：账目对不上（瓜涨了三倍，补胎还是五毛） | 读者被什么打动：动作自己说话（数两遍、不肯拔、看跑步机） |

注意这里的反直觉处：**余华的数字密度更高，但并不是「更冷」**。
他的数字是账，账承担情绪；李娟的数字是物，物只负责准确。
所以「密度」不能单独看，要和「数字在干什么」一起看。
（数字口径：阿拉伯数字 + 中文数词带量词/货币/度量/时间单位，同一规则计两人；
这是表层计数，不等于文学评价。）

### 对照三：都用「先替对方说话」，回答的结构不同

鲁迅一侧取自 `lx-1-收到.md`，毛泽东一侧取自 `maozedong-writing/examples/mz-1-读书.md`
（《读书要对症下药》）。两人都不打稻草人，但一个拆，一个安置。

| 鲁迅（lx-1） | 毛泽东（mz-1） |
|---|---|
| 族内原子：引其言而驳，1/10 | 族内原子：预设驳论、两点论，2/10 |
| 怎么引：「回个收到，是礼貌，是态度」，把对方的话说得比本人还周全 | 怎么引：「这话有一半道理」，一句承认，随即分两面 |
| 怎么答：顺着对方的词往下推，推到自相矛盾（「那它和不回的区别，也就只有这两个字了」） | 怎么答：承认合理面，再定主次（「两头都要，但不能平均用力」） |
| 结果：对方的话被拆掉 | 结果：对方的话被安置 |
| 共同点：都先让反方完整出场，再开口 | 共同点：都先让反方完整出场，再开口 |

同一族可以有两种完全不同的「正确写法」。区别不在谁更高明，
在你要的结局：拆掉一个说法，还是给两种说法排个次序。
这正是 `atoms/LIBRARY.md` 在「预设驳论」下写「引其言而驳」「两点论」「主客问答」
三个变体的原因。

## 四、37 个独有说明了什么

独有不是「更高级的原子」，是「暂时归不进共用族」的原子。它们的分布很集中：

| 引擎 | 独有/原子 | 独有的是些什么 |
|---|---:|---|
| 金庸 | 7/10 | 动作分镜、悬念埋扣、群像江湖、情义两难、历史嵌入、回目对仗、对白显性 |
| 汪曾祺 | 5/10 | 名物说解、宕开一笔、风俗铺陈、短句口语、文白相间 |
| 张爱玲 | 5/10 | 以物写心、色彩点睛、俗物入文、苍凉底色、声光切景 |
| 苏轼 | 4/10 | 窘中写乐、转念一歇、物各有主、亲证存疑 |
| 官方 | 3/10 | 接情绪、情绪套利、平视共谋 |
| 活人感 | 3/10 | 网络梗考古、科技梗引用、双关梗 |
| 李娟、人民日报、王小波、余华 | 各 2/10 | 视角、史料、姿态、结构类 |
| 毛选、脱口秀 | 各 1/10 | 开门见山、act-out |

可以读出一个粗略的分层：**小说叙事技法**（金庸那七条）需要长篇结构承载；
**语言质地**（汪曾祺、张爱玲那十条）是长期语感，拆成步骤也难迁移；
**选题与姿态**（官方三条、活人感三条）依附具体文体，换文体就失效。
这三类都不适合当第一课——不是它们不重要，是它们单独练不出来。

所以本层的顺序是：先把 18 个共用族练到能认、能写，再谈个人标记。
共用族是地基，独有是签名。地基没打好就练签名，写出来的是模仿，不是风格。

## 五、一个可核对的「原子链」

`renminribao-writing/examples/rmrb-1-工匠精神.md` 的稿尾自己标了原子链：

> 高位定调 → 时空坐标 → 历史纵深 → 以小见大 → 数据并举 → 四字格凝练
> → 排比递进 → 辩证回应 → 对仗收束 → 号召落点

把它翻译成族名：独有（高位定调、时空坐标）→ 古今对照 → 小处起笔 → 数据压舱
→ 金句断语 → 排比/三段 → 预设驳论 → 金句断语 → 号召落点。
十个动作，八族，顺序清楚。这就是组合的完整样本：不是「有文采」，
是「第几步做什么」可以逐步复述。

读任何一篇稿子，都可以做这张表：**第几句、哪个族、用了几次**。
做上十篇，你会发现自己反复用的只有五六族——那就是你现在的风格。
诊断工具（`tools/diagnose.py`）做的是同一件事的自动化版本，只是它只看表层特征。

## 六、口径与边界

**族数。** 本文说 19 族，是把「独有」也算作一个标签；`atoms/LIBRARY.md` 开头写
「18 族」，是不把「独有」当族。两个说法指的是同一批数据，差异只在计数方式。
本层统一口径：18 个共用族 + 1 个「独有」桶 = 19 个标签。

**引擎数。** `atoms/index.json` 覆盖 13 个引擎；仓库共 15 个引擎。
`feature-writing`（人物特稿）与 `gongwen-writing`（公文）走文种与流程规则，
原子写在各自 SKILL.md 里，尚未分族。所以「19 族 143 原子」不等于「15 个引擎全覆盖」。

**数字复现。** 本文所有族与计数都可一条命令重算：

```bash
python -c "import json,collections;d=json.load(open('atoms/index.json',encoding='utf-8'));f=collections.Counter(a['family'] for a in d);print(len(d),len(f),f['独有']);[print(k,v) for k,v in f.most_common()]"
```

**文本统计口径。** 对照二的「数字与账目词」= 阿拉伯数字 + 中文数词带量词/货币/度量/
时间单位（同一正则计两人）；它是表层计数，用来对照「数字在干什么」，
不构成对作者的评价。其余引文字数按去掉空白后的字符数计。

**没有引什么。** 本文不引任何受版权保护的原文；三组对照的引文全部来自
本仓库 `examples/` 的引擎试写稿（MIT，见 `LICENSE` / `NOTICE.md`），
每处 ≤30 字并标路径。`examples/` 是「按技法写的习作」，不是作者原文；
拿它做动作对照可以，做文本考证不行。

**没有借什么理论。** 全文没有引用外部研究或学术结论。「族」「组合」「密度」
都是从这个仓库 13 份原子表里归纳出来的工作概念；它们够用，但不宣称普遍正确。
如果你发现某条族定义与你的阅读经验冲突，以文本为准，改定义——这套材料的价值在可改，
不在权威。

**诊断的边界。** `tools/diagnose.py` 是启发式：只数首句长度、数字、引号、转折词、
末句形态这类表面证据，判不出反讽、留白、言外之意，也判不出好坏。
它的输出会写明「启发式估计，非人工判断」，并给每条规则注明依据与证据，供你反驳。
