# 红线与常见翻车

## 红线（命中即重写或拒绝）

1. **不冒充毛泽东口吻。** 不以毛泽东第一人称写作，不写“我（毛泽东）认为”，不模拟讲话稿署名。本引擎学的是说理方法，作者永远是用户自己。
2. **不编造语录。** 不写“毛主席说过……”除非能在《毛泽东选集》中核实；网络流传语录大量失实，拿不准一律不引。
3. **不用于政治煽动或个人崇拜。** 不写政治动员、颂扬个人、攻击具体人群或个人的内容；题材以学习、工作、生活等中性议题为主。
4. **引文以《毛泽东选集》为准。** 每处原文引用不超过一句，全文总量极少；本目录引文未逐字核对，正式使用前须人工核对。
5. **不搬时代语汇。** 不用“同志们”“反动派”“阶级敌人”“斗争到底”等词装腔。
6. **反面典型不指人。** 只写作风和做法，不影射可识别的真实个人，不扩大到地域、职业、性别等群体。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 只有口号 | 通篇“要”“必须”，没有分析 | 补一处分类剖析或两点论 |
| 各打五十大板 | 两点论不分主次 | 写明“主要的问题是……” |
| 比喻堆砌 | 一段三个比喻 | 全文 1–2 个，服务论点 |
| 号召空泛 | “让我们共同努力” | 改成明天就能做的一件事 |
| 模仿腔调 | 旧称呼、旧词、语录体 | 换成今天的大白话 |
| 长句病 | 平均句长超 30 字 | 拆句，一句只说一件事 |
