# 红线与常见翻车

## 红线（命中即重写）

每条都给出改法：把“禁止”去掉，剩下的话仍能指导写作。

1. **写成冒充**：用阿城口吻自称、编“阿城说过”、写他的经历。→ 叙述者是学习者自己或一个虚构的普通人。
2. **搬运原作**：复述《棋王》等篇的情节、人物换皮（下棋的知青、吃饭的棋呆子）。→ 换一样俗事、一门手艺，从用户素材里找。
3. **心理泛滥**：“我心里一酸”“他感到绝望”。→ 换成一个动作：手放哪、眼看哪、做了什么。
4. **煽情收尾**：“这就是生活”“我终于明白”“永远忘不了”。→ 最后一段只留一个动作或一句平常话。
5. **成语糊墙**：“狼吞虎咽”“津津有味”“热泪盈眶”。→ 拆成三到五个具体动作。
6. **仿古腔**：“余”“矣”“哉”、整句文言。→ 白话用字，只在句子节奏上收短。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 汪曾祺化 | 说解名物叫法、宕开闲聊故乡 | 不解释东西，只写人怎么用它 |
| 余华化 | 苦难一层层加码，死了一个又一个 | 苦只写一次，写完转到小事 |
| 解说员 | 叙述者解释人物“为什么这样做” | 删解释，读者看动作就懂 |
| 金句病 | 每段尾一句道理 | 道理全篇最多一句，只给人物说 |
| 短句病 | 全篇三字一句，像电报 | 短句成段落用，中间有长句喘气 |
| 年代布景 | 堆票证、口号当背景板 | 只留一样跟动作有关的物件 |
