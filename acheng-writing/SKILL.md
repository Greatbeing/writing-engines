# 阿城体——认知引擎版

> 阿城的好，不在故事奇，在字省：能用动作说的不用心理，能用一句说的不用两句，最重的地方反倒最轻。
> 蒸馏源：小说《棋王》《树王》《孩子王》，笔记体《遍地风流》，旁参随笔《闲话闲说》。
> 篇目与原子映射见 `references/sources.md`。阿城健在，作品在版权期：本目录只收拆解结论，不收原文句子。

## 能力边界

**能做**：用短句、白描、动作，把学习者自己经历或用户提供的一件事写硬、写省；把一段抒情过度的叙述改成只剩动作和对话。

**不能做**：

- **冒充阿城。** 不用他口吻自称，不编“阿城说过”，不编他的知青、云南、美国经历。
- **搬运原文。** 不复述、不拼贴、不洗稿《棋王》等篇的情节与句子；不写“下棋的知青”“吃饭的王一生”这类原作人物换皮。
- **伪造时代细节。** 票证、口粮、农场规矩、地方叫法拿不准就不写；不把用户没经历过的年代写成亲历。
- **煽情。** 苦写成苦本身，不写成“催泪”。

**盲区**：长篇结构、心理小说、对话驱动的喜剧不涉及；《威尼斯日记》式游记只取其省字，不取其题材。

## 核心认知

1. **字省到骨头。** 每句都问能不能删一半；形容词、心理、解释先删，剩下名词和动词。
2. **动作就是心理。** 人怎么拿碗、怎么咽、手放在哪，比“他很激动”准一百倍。
3. **俗事里有道。** 吃饱、活下去是最大的事；棋、字、树这类“道”从俗事里长出来，不高于它。
4. **重事轻写。** 越要紧的地方越少字；读者自己会把空白填满。
5. **叙述者不评。** 道理只让人物用家常话说一句，叙述者不接、不赞、不叹。

## 原子

10 个原子。定义、原作证据、原创示范、常见错误见 `references/atom-ops.md`。

| # | 原子 | 动作 | 出处（拆解概括） |
|---|---|---|---|
| 1 | 物事起笔 | 从一件事、一个场面直接起，不交代背景 | 《棋王》由车站送行的乱起笔 |
| 2 | 吃相 | 把吃写成一串郑重的连续动作，连残渣怎么收拾都写 | 《棋王》写人吃饭 |
| 3 | 动作代心理 | 不写想什么，只写手、眼、身子做了什么 | 通篇 |
| 4 | 一句立人 | 一句话或一个习惯立住一个人，后文不解释 | 《孩子王》的学生 |
| 5 | 白话对白 | 对话短，多不加“他说”，像截下来的 | 《棋王》两人对答 |
| 6 | 老话说道 | 让一个普通人用家常话说一句朴素道理，叙述者不接 | 《棋王》里老人谈棋 |
| 7 | 文言骨 | 白话用字，句子却收在短促的四字或文言节奏上 | 《遍地风流》最浓 |
| 8 | 重事轻写 | 最重的事用最少的字带过，或留白 | 《棋王》《树王》的关键处 |
| 9 | 俗中见道 | 吃、穿、活下去和棋、字、树并排放，不说谁高 | 《棋王》吃与棋，《孩子王》字典 |
| 10 | 冷收 | 结尾停在一个动作或一句平常话，不评、不叹 | 《棋王》《孩子王》结尾 |

## 组合规则

```
文章 = 起(物事起笔) + 行(吃相 / 动作代心理 / 一句立人 / 白话对白) + 转(老话说道 / 俗中见道) + 落(重事轻写) + 收(冷收)
贯穿：动作代心理，文言骨
```

**一篇用 5–7 个原子。动作代心理全篇贯穿；吃相或一门手艺至少一处；老话说道全文最多一次；文言骨只点在段尾，全文不超过五处。**

## 风格指纹（写完逐项核对，两项不过就重写）

1. **心理动词少**：“想、觉得、感到、心里、内心”全文 ≤ 3 处。
2. **句子短**：平均句长 ≤ 16 字；至少一段连续三句都 ≤ 8 字。
3. **形容克制**：一句最多一个形容词；比喻全文 ≤ 2 个。
4. **有一串动作**：吃相或手艺处，至少 4 个连续动作。
5. **对白不挂牌**：对话至少一半不带“说”字提示语。
6. **冷收**：最后一段 ≤ 3 句，无评价词、无感叹号。

## 红线（写作规则）
- 情绪写成动作：手、碗、筷子、脚步替人说话。
- 道理只给人物说一次，用他自己的土话；叙述者接下来写一个动作。
- 最重的事写一句，写完就转到一件小事上。
- 年代细节只来自用户或作者本人的素材；拿不准写成“听说”，或不写。
- 与 wangzengqi-writing 的分界：不说解名物、不宕开闲聊，“我”在场里受着；与 yuhua-writing 的分界：苦只写一次，不层层加码。
- 红线与常见翻车见 `references/red-lines.md`。

## 工作流程

1. 问清题目、篇幅、用途（不清楚时只问一句）。
2. 要素材：一个人、一件事、一样吃的或一门手艺。用户没给就自行构造，文末注明「综合创作」。
3. 找“硬处”：这件事里最重的一下，决定用几个字带过。
4. 找“动作”：吃相或手艺拆成至少 4 个连续动作。
5. 选 5–7 个原子，先写一行原子链。
6. 成稿后逐句删：删心理、删形容、删解释。
7. 对照风格指纹自检，跑 `tools/ai-flavor-checker.py --engine acheng-writing`，报告哪几项过、哪几项没过。
