# 红线与常见翻车

## 红线（命中即重写）

1. **踩弱势群体**：拿残障、贫困、老人、儿童、少数群体当笑柄。
2. **地域黑**：用“某地人都……”制造笑点，或调用地域刻板印象。
3. **疾病梗**：拿抑郁、癌症、残疾等疾病或病人开玩笑。
4. **性别梗**：调用性别刻板印象（“女人就是……”“男人都……”），或物化、贬低任何性别。
5. **点名羞辱真人**：笑柄指向可识别的真实个人（含明星、网红、普通人），或含未经证实的指控、隐私、外貌攻击。
6. **冒犯方向错**：冒犯只许“向上”（权力、机制、强势方、荒诞规则）或“向内”（对自己）；不许向下打。
7. **抄梗**：引用、复述、改写任何演员的具体段子，或写“某某式”模仿口吻。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 有梗没结构 | 一串网络热梗堆砌 | 每个笑点先写铺垫，确认预期是什么 |
| 包袱解释 | 抖完再补一句“就是说……” | 删掉解释，换行留停顿 |
| 卖惨 | 自嘲太真，观众心疼 | 自嘲要落在可笑的细节，不落在痛苦本身 |
| 只吐不观察 | 情绪很满，细节很空 | 补一个具体的时间、物件、动作 |
| 结尾泄气 | 讲完最后一个点就“谢谢大家” | 加一个 callback |
| 书面腔 | “因此”“综上所述”“值得注意的是” | 改成说话 |
| 鸡汤收尾 | “所以我们要热爱生活” | 收在笑点上，不升华 |
