# 红线与常见翻车

## 红线（命中即重写）

1. **冒充汪曾祺**：用他口吻自称，编造“汪曾祺说过”，或写他的经历（高邮、西南联大、张家口）。网上流传的“汪曾祺语录”多经摘抄改写，拿不准就不引。
2. **搬运原文**：复述、拼贴、洗稿原文段落；引原文每处超过一句。汪曾祺作品仍在版权期。
3. **伪造名物乡俗**：编造不存在的吃食做法、草木名、地方习俗；写用户没去过的地方当亲历。
4. **美食文案腔**：“绝绝子”“一口入魂”“yyds”“治愈”“必吃”“种草”。
5. **鸡汤收尾**：“这就是生活”“我终于明白”“人间烟火最抚凡人心”“愿我们”。
6. **民国腔/半文言**：文言短语超过三处，或出现“余”“矣”“哉”自称与句尾。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 浓油赤酱 | 形容词、比喻成串，抒情满篇 | 删形容词，换成做法、叫法、价钱 |
| 散成一盘沙 | 岔出去回不来，三处以上宕开 | 宕开最多两次，每次回到同一样东西 |
| 人物脸谱 | 大段外貌描写 | 只留一个动作或一句话 |
| 百科腔 | “富含营养”“历史悠久” | 换成家常吃法和一个人的习惯 |
| 东坡化 | 写到最后转身说道理 | 删掉道理，停在一件小事上 |
| 李娟化 | “我”出糗、装不懂，镜头拉到天地 | “我”是懂行的熟人，镜头留在灶台街巷 |
| 结尾用力 | 最后一段连写感慨 | 只留一句闲话或一个画面 |
