# tools · 评测工具

> 评测器是「教人写作」产品的核心反馈环——写完不是结束，打过分才是开始。

## ai-flavor-checker.py v0.1

把反 AI 味红线变成**可执行的评分**：输入文本 → 总分 0-100（越高越 AI 味）+ 六维报告 + 行级命中。

```bash
python3 tools/ai-flavor-checker.py <文件路径>
# 或
python3 tools/ai-flavor-checker.py --stdin < input.txt
```

### 六维

| 维度 | 上限 | 检测什么 |
|---|---|---|
| 书面腔 | 30 | 官腔/书面连词（值得注意的是/综上所述/赋能/抓手…） |
| 空转词 | 15 | 抽象名词密度（价值/意义/格局/认知…） |
| 排比堆叠 | 15 | 连续句尾同构 ≥3 + 引号金句密度 |
| 破公式 | 10 | 「不是…而是…」频率 |
| 长句 | 15 | >60 字句子 |
| 口语抵充 | -15 | 口语标记（说白了/其实/搞/呗…）——抵消 |

### 分级

```
<30   活人感
30-49 轻度 AI 味
50-69 明显 AI 味
≥70   AI 味爆表
```

### 实测基准（2026-11-25）

| 样本 | 总分 | 判定 |
|---|---|---|
| 合成 AI 腔文本（222 字） | 45 | 轻度 AI 味（书面腔 30/30 爆表）|
| 三联体·放弃青云志重写版 | 3 | 活人感 ✓ |
| 赵本山·活人感 | 0 | 活人感 ✓ |
| 官方体·机会不在多 | 0 | 活人感（此文体避开 AI 腔词表）|

### 校准说明（重要）

v0.1 面向**活人感叙事/新媒体文**。论文、公文、官方体自带书面腔是文体特征，高分不代表文体失败——**AI 味 ≠ 书面腔，而是「书面腔里没有血肉」**。

v0.2 方向：文体感知评分（按引擎标准打分）+ 行级建议生成（不只指出问题，给出改写提示）——教学产品需要的是「提建议的教练」，不是「判卷的老师」。

### 词表哲学

保守收录，宁可漏检不误报。词表即知识——每次实战发现新的 AI 腔词，直接追加（v0.1 已内置：书面腔 34 / 空转词 26 / 口语 19）。
