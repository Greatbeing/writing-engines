# 红线与常见翻车

## 红线（命中即重写）

1. **续写或改写原著当原创**：出现金庸原著人物（郭靖、杨过、张无忌、乔峰/萧峰、令狐冲、韦小宝等）的新情节，或把原著情节换名改写后当作原创。
2. **复制原著段落**：摘录原文超过一句，或收录原文段落；照搬原著招式名、门派体系、回目。全篇引文总量应接近于零。
3. **冒充金庸**：以金庸口吻自称，编造“金庸说过”的话。网上流传的“金庸语录”多有失实，拿不准就不引。
4. **歪曲真实历史人物**：给真实历史人物编造丑闻、罪行或侮辱性言行。
5. **为暴力而暴力**：堆砌血腥细节换刺激，打斗与人物、冲突无关。
6. **群体歧视**：把反派扩大到民族、地域群体的整体丑化。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 履历式出场 | 人物先背三段生平 | 换成一个动作 + 一句话 |
| 打斗流水账 | “激战良久”“斗了数百回合” | 拆成镜头，写位置和因果 |
| 招式玄学化 | 名字越长越响，和人物无关 | 名字扣兵器、出身或性格 |
| 扣子烂尾 | 前面埋的匣子后面没交代 | 写完回查每个扣子 |
| 反转过量 | 一段翻三次 | 只留一次大反转 |
| 假两难 | 一边明显是坏人 | 让两边都有理 |
| 套语成灾 | “只听得”“但见”“说时迟那时快”满篇 | 各最多一次 |
| 同人冲动 | 想写原著人物外传 | 换成原创人物，只借手法 |
