# 第一回 三帮同席贺新酒 一杯未尽散旧盟

乾隆二十年秋，运河上漕船正多，淮安府清江浦的沈家摆了四十桌喜酒。

沈家嫁女，嫁的是本地米行的少东。论江湖，沈家是“铁秤门”，三代给漕帮管秤，一杆秤从不让人短一两。掌门沈怀秋五十八岁，个子不高，右手常年捏着一枚铜秤砣，走路时在掌心里转，转得极匀。

来的客人里有三家最显眼。

头一家是漕帮的窦三爷。他嗓门大，进门先喊：“老沈，今天这酒要是兑了水，我连桌子一块扛走！”说完自己先笑，满院子都听得见。

第二家是盐枭出身的“青袍会”，来的是个瘦长的中年人，姓柯，一身青布袍子洗得发白。他不喝酒，只喝茶，每喝一口都要看一眼门口。

第三家最安静。淮北“十里桥”来了一个老妇人，拄一根枣木拐杖，带着两个后生。她坐下后一句话也没说，拐杖却一直横放在膝上，没靠在桌边。

酒过三巡，沈怀秋站了起来。

他把铜秤砣放在主桌正中，说：“各位，沈某今天嫁女，也趁这个日子说一件事。铁秤门从今天起，不再给漕帮管秤，沈某退出江湖。”

院子里静了一下。

窦三爷第一个拍桌子：“老沈，你退了，那秤谁管？这几年运河上的米价，全靠你那杆秤压着！”

柯先生放下茶碗，慢慢说：“沈掌门要退，总得说个缘故。秤是死的，人心是活的。秤不在你手里，在谁手里？”

老妇人还是没说话。她身边一个后生想站起来，她用拐杖在他脚背上轻轻一点，那后生就又坐下了。

沈怀秋道：“缘故只有一个。去年冬天，十里桥饿死了三十七个人。他们的米，是从运河上过来的，过的是我的秤。”

窦三爷脸色变了：“那是年景不好！”

“年景不好是真的。”沈怀秋说，“秤也不准，也是真的。”

他把秤砣翻过来，底下有一道新磨的口子，亮得刺眼。“这枚砣，被人磨轻了二钱。我管了三十年秤，竟没发觉。”

柯先生的手停在了茶碗上。

满院子的人都看向窦三爷。窦三爷涨红了脸，站起来要说话，沈怀秋却摆了摆手。

“不是窦三。”他说，“砣是我自己的。每天在我手里转，转了一年，就磨轻了。”

没有人出声。

“我的手每天都在动，我以为是在稳住秤。”沈怀秋说，“原来是一直在磨它。三十年的规矩，坏在我自己的手上。这样的人，还管什么秤？”

老妇人这才开口，声音很哑：“沈掌门，十里桥的人不是来要你退的。是来问你，那二钱，谁来补？”

沈怀秋朝她深深一揖：“沈家今年的米行分红，全部送到十里桥。我女儿的嫁妆，已经折成了米，昨晚装上船了。”

新娘坐在内院帘子后面，一直没出来。后来帮厨的人说，那天新娘头上只插了一根木簪子。

窦三爷愣了半晌，端起酒碗一口喝干，说：“老沈，你这一退，我这杯酒不知道该算喜酒还是散伙酒。”

柯先生起身，把青袍下摆理平，对沈怀秋拱了拱手，什么也没说，先走了。

老妇人拄着拐杖站起来，走到主桌前，拿起那枚铜秤砣，在手里掂了掂，又放下。

“轻了。”她说，“也好，以后拿着不累。”

那一晚，沈家院子里的灯一直亮到后半夜。有人说看见沈怀秋一个人坐在空桌边，手心里空空的，还在转。
