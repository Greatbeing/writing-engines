# 金庸体——认知引擎版

> 金庸的好看，不在打得多热闹，在每一招都打在人物身上：武功是性格，江湖是人情，历史是棋盘。
> 蒸馏源：《射雕英雄传》《神雕侠侣》《倚天屠龙记》《天龙八部》《笑傲江湖》《鹿鼎记》等长篇的叙事结构。
> 篇目与原子映射见 `references/sources.md`。金庸作品受著作权保护，本目录只收拆解结论，不收原文段落；引文未逐字核对。

## 能力边界

**能做**：写人物出场即立住、打斗有画面与节奏、悬念层层翻的原创武侠片段；把这些手法迁移到现代叙事，让人物和冲突“立起来”。

**不能做**：

- **续写或改写原著。** 不写郭靖、令狐冲、乔峰、韦小宝等原著人物的新故事，不把改写原著情节当原创。
- **复制原文。** 不摘录原著段落、不仿写原著具体招式名与门派体系；引用每处不超过一句，全篇最好不引。
- **冒充金庸。** 不以金庸口吻自称，不编造“金庸说过”的话。
- **歪曲真实历史人物。** 历史只作背景与棋盘，不给真实人物编造丑闻。

**盲区**：金庸的修订版差异、诗词回目的格律细节、评点式后记不涉及；长篇的多线结构只取“片段内可用”的部分。

## 核心认知

1. **人物一出场就要“定型”。** 一个动作、一句话、一处细节，读者就记住他是谁。
2. **武功是性格的外化。** 怎么出手，就是怎么做人；打斗推进的是人物关系，不是血条。
3. **悬念是钩子，反转是答案。** 先埋一个读者想知道的东西，在最该揭开的时候翻过来。
4. **最好看的冲突在“情”与“义”之间。** 两边都对，人物只能选一边，选了就要付代价。
5. **江湖嵌在历史里。** 个人恩怨放在一个真实的大时代背景下，故事就有了分量。

## 原子

10 个原子。定义、原作证据（结构概括）、原创示范、常见错误见 `references/atom-ops.md`。

| # | 原子 | 动作 | 出处（结构参照） |
|---|---|---|---|
| 1 | 出场立人 | 用一个动作 + 一处外貌异处 + 一句话，让人物一出场就立住 | 《鹿鼎记》《射雕》开篇人物登场 |
| 2 | 动作分镜 | 打斗拆成可视的镜头：位置、距离、一招一式、因果，快慢交替 | 《天龙八部》聚贤庄 |
| 3 | 招式命名 | 给招式起有意象、有来历的名字，名字暗示性格或门派 | 各部武功体系 |
| 4 | 悬念埋扣 | 先抛一个读者想知道却暂时不说的东西（匣中物、来历、旧约） | 《笑傲江湖》金盆洗手 |
| 5 | 反转揭底 | 在冲突顶点翻出身份、旧事或真相，改变所有人的立场 | 《天龙八部》身世揭露 |
| 6 | 群像江湖 | 一场戏里几方人物各有立场、各有算盘，几笔分出差别 | 《笑傲江湖》衡山城 |
| 7 | 情义两难 | 让人物在私情与道义、恩与仇之间二选一 | 《天龙八部》《射雕》 |
| 8 | 历史嵌入 | 用一个真实年号、战事、制度作背景，个人命运压在大势下 | 《射雕》《鹿鼎记》 |
| 9 | 回目对仗 | 章节标题用对仗句，上下句各点一处情节 | 《天龙八部》《鹿鼎记》回目 |
| 10 | 对白显性 | 不同人物说话方式不同，一句台词就能听出是谁 | 《鹿鼎记》韦小宝式对白 |

## 组合规则

```
片段 = 题(回目对仗) + 起(历史嵌入 / 出场立人) + 扣(悬念埋扣) + 打(动作分镜 × 招式命名 × 对白显性) + 翻(反转揭底) + 压(情义两难 / 群像江湖) + 留(余韵或新扣)
```

代表段落的原子链还原（拆解结论，非原文；情节细节凭阅读整理，未逐字核对）：

- 《射雕英雄传》开篇牛家村 ＝ 历史嵌入（说书人讲靖康旧事，宋金对峙为底色）→ 出场立人（郭、杨两家男人的性情各一笔）→ 悬念埋扣（雪夜来客）→ 动作分镜（道士与官兵相斗）→ 情义两难（两家命运从此被大势撕开）
- 《天龙八部》杏子林至聚贤庄 ＝ 悬念埋扣（帮中密谋）→ 反转揭底（主角身世被当众揭开）→ 情义两难（与旧友断义）→ 群像江湖（各派英雄各怀立场）→ 动作分镜（以一敌众，快慢交替）
- 《笑傲江湖》衡山城金盆洗手 ＝ 群像江湖（各派宾客齐聚）→ 悬念埋扣（不速之客与令旗）→ 反转揭底（主人与“魔教”中人的私交被揭）→ 情义两难（知音之情与门派之义）
- 《鹿鼎记》主角初入宫廷段 ＝ 出场立人（市井少年的油滑与机灵）→ 对白显性（满口市井腔调）→ 历史嵌入（康熙初年权臣当道）→ 反转揭底（以小搏大，局面翻转）

**一个片段用 5–7 个原子。出场立人与动作分镜几乎必选；反转一篇只翻一次大的。**

## 现代题材迁移

| 原子 | 迁移到现代的写法 |
|---|---|
| 出场立人 | 新总监进会议室第一个动作是把空调调低两度 |
| 动作分镜 | 谈判拆成回合：谁先开价、谁先看表、谁先站起来 |
| 招式命名 | 给人物惯用的手段起外号（“三天不回邮件法”） |
| 情义两难 | 提拔老朋友还是按规矩用外人 |
| 历史嵌入 | 把故事放在一次真实的行业周期、政策节点下（不歪曲真实人物） |

## 风格指纹（写完逐项核对，两项不过就重写）

1. **主要人物出场三句内立住**：有一个动作或外貌异处 + 一句显性格的话。
2. **打斗可视**：至少一段动作写清位置与因果，读者能在脑中“回放”，不靠“激战良久”带过。
3. **至少一个原创招式名**，且名字与人物或兵器有关。
4. **有一个悬念在前面埋下、在后面揭开**。
5. **有一处情义两难**，人物的选择付出了代价。
6. **全部人物、门派、招式原创**；无原著人名、无原文段落。

## 写作规则

- 叙述用晓畅的白话，略带古意即可，不写文言、不堆“只听得”“但见”套语（全篇各最多一次）。
- 打斗句子短、动词实：点、扫、挑、缠、断；快的地方连写，慢的地方停一下写人物的念头或旁人的反应。
- 对白不加“冷冷地说”“怒道”泛滥，性格靠台词本身。
- 历史背景只取年号、地名、大事，不给真实人物编造言行。
- 不引原文；确需借用，最多一句，并在 sources 中注明、标注未核对。
- 红线与常见翻车见 `references/red-lines.md`。

## 工作流程

1. 问清题材（武侠 / 现代迁移）、篇幅、时代背景（不清楚时只问一句）。
2. 定核心冲突：谁和谁、为了什么、情与义各在哪一边。
3. 定悬念物与反转点：先想好结尾要翻的那张牌，再往前埋扣。
4. 选 5–7 个原子，先写一行原子链和回目。
5. 成稿，对照风格指纹自检，过一遍红线（尤其原著人名、原文），报告哪几项过、哪几项没过。
