# 毛泽东文章体——说理写作学习版

> 这种文章的力气，不在调门高，在把道理讲得老百姓听得懂：先摆问题，再分开说，最后告诉你怎么办。
> 蒸馏源：《为人民服务》《纪念白求恩》《愚公移山》《反对党八股》《改造我们的学习》
> 《中国社会各阶级的分析》《矛盾论》等。篇目与原子映射见 `references/sources.md`。
> 版权与引文：原文不在本目录存放，只保留拆解结论；引文以《毛泽东选集》为准，本目录引文未逐字核对。

## 能力边界

**能做**：写观点清楚、层次分明、口语化的议论文；把一篇空泛的说理文改得有问题、有分析、有办法；拆解议论文的论证骨架。

**不能做**：

- **冒充毛泽东。** 不以毛泽东第一人称写作，不写“毛主席教导我们”式的伪引文，不编造语录。
- **政治煽动与个人崇拜。** 不用于政治动员、颂圣、攻击具体人群或个人。
- **照搬旧词。** 不堆“同志们”“反动派”“斗争”等时代语汇；产出是今天的普通白话。
- **替代事实。** 两点论是分析方法，不能代替调查；用户没给的数据和经历不编造。

**盲区**：诗词、电报、军事文献不涉及；《矛盾论》只吸收“主要矛盾 / 两点论”的说理形式，不讲哲学体系。

## 核心认知

1. **问题先行。** 第一段就把要回答的问题摆出来，不绕圈子。
2. **分析就是分开。** 把一团事分成几类、几条、几个方面，道理自然显出来。
3. **两点论，抓重点。** 看到好的一面也看到坏的一面，但要说清哪个是主要的。
4. **用老百姓的话讲大道理。** 一句俗语、一个比喻，胜过十个术语。
5. **落到行动。** 说完道理要说怎么办，号召要具体、亲切，不空喊。

## 原子

10 个原子。定义、原作证据（结构描述为主）、原创示范、常见错误见 `references/atom-ops.md`。

| # | 原子 | 动作 | 出处（手法所在） |
|---|---|---|---|
| 1 | 开门见山 | 第一句就提出问题或亮出论点 | 《中国社会各阶级的分析》以设问开篇 |
| 2 | 分类剖析 | 把对象按标准分成几类，逐类说明 | 《中国社会各阶级的分析》 |
| 3 | 分条列举 | “第一……第二……”逐条列出罪状或办法 | 《反对党八股》列八条 |
| 4 | 俗语比喻 | 用民间俗语、日常比喻讲道理 | 《反对党八股》“对症下药”；《愚公移山》寓言 |
| 5 | 两点论 | 一分为二地看，再指出主要方面 | 《矛盾论》 |
| 6 | 反面典型 | 画出一种错误做法的样子，给它起个名 | 《改造我们的学习》对主观主义作风的描画 |
| 7 | 正面榜样 | 用一个具体的人或事立标杆 | 《纪念白求恩》《为人民服务》 |
| 8 | 预设驳论 | 先说出“有人会说……”，再回答 | 《反对党八股》《为人民服务》中的答疑段 |
| 9 | 短句排比 | 短句连用、排比推进，增加节奏和力量 | 《纪念白求恩》结尾的排比 |
| 10 | 亲切号召 | 结尾提出具体可做的要求，语气平实 | 《愚公移山》《为人民服务》结尾 |

## 组合规则

```
文章 = 提(开门见山) + 析(分类剖析 / 两点论 / 反面典型 / 正面榜样) + 证(俗语比喻 / 预设驳论) + 办(分条列举 + 亲切号召)
```

代表作原子链还原（结构概括，非原文）：

- 《中国社会各阶级的分析》＝ 开门见山（设问谁是敌谁是友）→ 分类剖析（逐个阶级）→ 两点论（各阶级的两面性）→ 结论
- 《反对党八股》＝ 开门见山 → 分条列举（八条）→ 俗语比喻 → 预设驳论 → 亲切号召
- 《纪念白求恩》＝ 正面榜样 → 反面典型（对照某些人的作风）→ 短句排比 → 亲切号召
- 《愚公移山》＝ 俗语比喻（寓言）→ 正面榜样 → 亲切号召

**一篇用 4–6 个原子。必须有“提”和“办”，中间至少一个分析类原子。**

## 风格指纹（写完逐项核对，两项不过就重写）

1. **开头三句内提出问题或亮出论点**，不铺垫背景。
2. **至少一处分条**（第一、第二……或“一种是……另一种是……”）。
3. **至少一处两点论**：承认对方有道理的一面，再指出主要问题。
4. **至少一句俗语或日常比喻**，且服务于论点，不是装饰。
5. **平均句长 ≤ 25 字**，有一处短句排比。
6. **结尾是可执行的号召**，不是空喊口号；不出现伪引语、不冒充口吻。

## 红线（写作规则）
- 用“我们”“我看”“有人说”，口语化，但不用“同志们”等称呼。
- 术语换成大白话；一个概念第一次出现时用一句话说清。
- 反面典型只写做法，不指向真实个人或群体。
- 原文引用：默认不引；确需引用每处不超过一句，以《毛泽东选集》为准，拿不准不引。
- 红线见 `references/red-lines.md`。

## 工作流程

1. 问清题目、篇幅、读者（不清楚时只问一句）。
2. 把题目改写成一个问题：“××到底怎样才算……？”
3. 列出要分的类或条（2–4 个），定下主要矛盾是哪一个。
4. 选 4–6 个原子，先写一行原子链。
5. 成稿，对照风格指纹自检；跑 `python tools/ai-flavor-checker.py 稿件.md`，报告字数与平均句长。
