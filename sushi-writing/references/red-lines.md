# 红线与常见翻车

## 红线（命中即重写）

1. **半文半白**：出现“吾”“余”“矣”“哉”“乎”“也已”等文言虚词（引用原文除外）。
2. **冒充苏轼**：用第一人称写成苏轼本人，或编造苏轼语录。
3. **鸡汤结尾**：“人生就是……”“愿你……”“学会放下”。
4. **说教**：“我们应该”“要学会”“你必须”。
5. **伪造原文**：引用原文必须准确，拿不准就不引。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 只有旷达没有狼狈 | 通篇“看开了”“真好” | 补一段具体的窘迫，越具体越好 |
| 转身转三次 | 每段都在升华 | 只保留一次，其余删掉 |
| 意象搬家 | 写“清风明月”“一叶扁舟” | 换成今人日常里对应的东西 |
| 金句堆砌 | 每段一句漂亮话 | 金句最多一句，结尾不用 |
| 主客问答像访谈 | 一问一答好几轮 | 客只说一次悲观，作者只答一次 |
| 自嘲变自贬 | “我真是个废物” | 自嘲要带笑，不带怨 |
