风 一何为采风

周代设采诗之官，行于四方，收集民歌，以观风俗，知得失。《诗经》的「国风」，就是这样来的。

古人采风，目的不在于把歌攒起来，而在于从歌里看出一地的规律。这个仓库做的是同一件事：从真实文本里，拆出一种文体的造法。

采，是拆解，不是收藏。— 所以这里没有范文合集，也不保存语料全文
风 二一个引擎

一种文体，本质上是一套作者没说出来的操作规则。

写作课教你的「要有细节」「要克制」「要有网感」，是这些规则被总结之后的样子，不是它们运转的样子。引擎把它拆成三道，各管一段。

原子ATOMS

可复用的最小技法与组合规则。管「怎么写」。

指纹FINGERPRINT

可数的风格特征。管「像不像」，能自检、能打分。

红线RED LINES

一碰就露怯的禁区。管「不能怎么写」。

  • 只有原子 → 一本无法自检的范文集
  • 只有指纹 → 只能判卷，不能写作
  • 只有红线 → 绕回提示词模板
风 三模板与引擎
提示词模板采风引擎
给你什么成品长什么样成品怎么长出来的
能不能自检不能，只能凭感觉指纹可数、红线可查、checker 可打分
会不会生长用完即弃每次实战反哺
覆盖范围一个腔调一种文体的全部构件
换一种文体从头再写一份换一套原子排序，用的是同一批原子

模板让你像它，引擎让你不必像它。

风 四引擎清单

17 个引擎，分五种文体归属。

每个引擎都走同一份七节契约（SPEC.md）、都带 test-prompts.json 与可判定的断言。分级只有两种：可用（过契约、过断言、有完整产出）与试用（结构齐备，但样本与实战反馈还少）。卡上写的是这个引擎真正管的事，不是形容词。

议论 ARGUMENT

讲一个道理，让它在别人心里立住。差别不在「有没有观点」，在立场、证据与锋利度：时评吃情绪，社论吃站位，杂文吃眼光。

庙 堂 之 风

浙江宣传体

zhexuan-writing

体制内爆款写作法。12 个原子操作 + 组合规则 + 风格指纹；选题困难时用「情绪套利三问」自己找题。核心不是文体模式库，是可生成新文章的认知引擎。

适用 时评 · 政论 · 主旋律 · 纪念文
社 论 之 风

人民日报评论

guanfang-writing

高位定调、历史纵深、四字格与排比递进、辩证回应。与官方体的边界写在能力边界里：要爆款、破圈用它；要庄重、可上头版用这个。

适用 社论 · 评论员文章 · 人民时评
讲 理 之 风

毛泽东文章体

mao-writing

开门见山、分类剖析、分条列举、两点论、俗语比喻、短句排比。只学怎么写，不学立场；冒充口吻、编造语录一律拒绝。

适用 议论文 · 说理短文 · 演讲稿
冷 眼 之 风

鲁迅体

luxun-writing

小处切入、正话反说、揭底一句、冷笔白描。把人人习以为常的东西，指给你看它的骨头。原文公版（鲁迅 1936 年逝世）。

适用 杂文 · 短评 · 社会现象批评
趣 味 之 风

王小波体

wangxiaobo-writing

一本正经地推演，推到荒谬处让人笑出来，再以「有趣」为尺度。科学类比、动物寓言、沉默者立场。不冒充口吻，网上伪语录拿不准就不引。

适用 说理杂文 · 随笔 · 反驳「正确的废话」

叙事 NARRATIVE

写人与处境的变化。共同点是时间在推进、细节在承重、结尾不升华；分野在温度和距离——特稿近身，余华退后，金庸把冲突架在人情与局势上。

人 间 之 风

特稿

feature-writing

人物特稿体。特稿不是写人，是写「处境与变化」——人是处境的总和，时间是核心变量。附选题四问：先判断这个题够不够格写。

适用 人物特稿 · 深度报道 · 人物群像
零 度 之 风

余华体

yuhua-writing

零度叙述、重复结构、死亡轻写、口语对话推进。写死的时候不眨眼，读者替他哭。把煽情的苦难叙事改冷、改轻、改出重复的节奏。

适用 短篇叙事 · 小小说 · 普通人的苦难
江 湖 之 风

金庸体

jinyong-writing

出场立人、动作分镜、悬念埋扣、群像江湖、情义两难。武功是性格，江湖是人情。人物、门派、招式均须原创，不写原著续写与同人。

适用 原创武侠片段 · 叙事手法迁移
白 描 之 风

阿城体

acheng-writing

省到骨头的白话叙事。动作代心理、吃相、一句立人、重事轻写、冷收；道理只给人物说一次。与汪曾祺体的分界：汪是懂行的人在说，阿城是饿过的人在吃。

适用 短篇 · 人物小记 · 叙述去水分

散文 ESSAY

写自己的日子与身边的风物。共同点是从小处落笔、以白描为主、情绪不外放；差别在「我」的姿态——东坡会转身，汪曾祺不转身，李娟蹲下来看，张爱玲在一旁看得清。

旷 达 之 风

苏轼白话体

sushi-writing

即事起兴、窘中写乐、主客问答、转念一歇。东坡的好不在辞藻，在「看得开」的那一下转身。原文公版，用今天的白话写。

适用 白话随笔 · 游记 · 读书杂感
淡 笔 之 风

汪曾祺体

wangzengqi-writing

闲闲起笔、名物说解、手艺细写、文白相间、轻轻一放。情绪始终是平的，不转身、不说理。把一篇用力过猛的抒情散文改淡。

适用 吃食草木 · 手艺人 · 节令风俗
天 真 之 风

李娟体

lijuan-writing

天真视角、琐事铺满、风物白描、镜头拉远、一句轻叹。把一件谁都不当回事的小事，看得像第一次看见。写的是学习者自己的日子。

适用 家人小记 · 季节风物 · 日常散文
苍 凉 之 风

张爱玲体

zhangailing-writing

格言起收、刁钻比喻、以物写心、冷眼算盘。把人心里那点算盘放到一件衣服、一盏灯上。产出是今天的白话，不写民国腔与旗袍月亮。

适用 都市散文 · 人情小品 · 短篇片段

实用 APPLIED

面向具体场景的写作，有传播上的硬约束：一段要让人读下去，一段要让人听下去。前者靠具体，后者靠节奏。

城 市 之 风

活人感

sanlian-writing

城市观察文。具体的人、具体的物、具体的抱怨、具体的快乐；幽默、口语、松弛收尾。21 个原子，也能反向给已有文本去 AI 腔。

适用 公众号叙事文 · 城市观察 · 网感文案
舞 台 之 风

脱口秀稿

standup-writing

观察切口、铺垫—包袱、三段式、act-out、callback。好笑不是说笑话，是让观众比你先一步想到，又在最后一秒发现想错了。不模仿具体演员。

适用 单口稿 · 开放麦 · 短视频口播
凡 尔 赛 之 风

凡尔赛体

versailles-writing

用抱怨、谦虚、求助的口吻炫耀：不经意带出、抱怨式炫耀、他人代夸、反问求助。只炫一样，从不点破。也能反向用：给一段文字打「凡度」，翻成直白话。

适用 玩梗 · 讽刺 · 凡尔赛诊断

公文 OFFICIAL DOCUMENT

有法定格式与行文关系的一类。先守规矩，再谈表达：文种选错，写得多好都不对；格式不齐，语气再准也不算成品。

规 矩 之 风

公文

gongwen-writing

对齐 GB/T 9704-2012 与 15 个法定文种。九步流程：需求澄清、文种判定、素材盘点、情境化语气、篇幅控制、规范结构、默念自查。不越位、不代决，只给写法。

适用 通知 · 报告 · 请示 · 函 · 会议纪要

17 个引擎都能反向用：给它一篇现成文章，它按原子链拆解、做红线体检，告诉你用了哪几招、哪几处露怯、怎么改。分级与阈值见 CONTRIBUTING.md。

风 五原子总库

17 个引擎不是 17 套话术，是同一批原子的不同排序。

把各引擎的原子表摊开对照，重复率比想象的高：鲁迅的「小处切入」、汪曾祺的「闲闲起笔」、脱口秀的「观察切口」、官方体的「场景钩」，做的是同一个动作——从一个极小、人人见过的东西切进去。于是有了跨引擎的原子总库：各引擎的原子文件保持原样，只在每个原子下加一行族标签，再按族汇总。

族里记的是通用定义，引擎里记的是变体差异——同一个动作，鲁迅冷、汪曾祺闲、脱口秀要观众「对对对」。这就是这个仓库最重要的一句话：

不同作者 = 同一批原子的不同组合。— 风格不是另一套零件，是同一批零件的另一种顺序与密度

人读的汇总页是 atoms/LIBRARY.md，机器读的是 atoms/index.json。两边对不对得上不靠自觉：lint_skill.py 的 A1–A3 三条检查，族标签缺一行、与索引不一致、索引里有而原子文件里找不到，都会报错。

「独有」不是一个族，是47 个只在单一引擎出现的动作——金庸的动作分镜、张爱玲的色彩点睛、李娟的天真视角都在这里。它们是总库的下一批候选：再有两个引擎用到同一个动作，就该给它一个族名。

风 六造一个引擎

引擎不是攒出来的，是造出来的。

  1. 采样选一种边界清楚的文体，收集真实、成色足的文本。
  2. 拆原子逐篇拆出最小技法，归并成可组合的操作。
  3. 立指纹把「像」变成可数的特征，能计量、能对照。
  4. 划红线写下一碰就露怯的禁区，并给出替代写法。
  5. 实战回灌用引擎写真文章，失败处反哺原子与红线。

每个引擎遵守同一份七节契约（见 SPEC.md），并通过 lint_skill.py 的十项检查才能收录。

风 七安装与使用

SKILL.md + frontmatter 是通用格式。以 OpenClaw 为例：

git clone https://github.com/Greatbeing/writing-engines.git
# 17 个引擎目录各自自包含，按需拷，也可以全拷
cp -r writing-engines/*-writing ~/.openclaw/workspace/skills/

Claude Code 或其它支持 SKILL.md 的宿主：把引擎目录放进对应的 skills 路径即可。目录自包含，无代码依赖。

一句话需求进，一篇文章出。写完可以自检：

# 按引擎给一篇文章打 AI 味分
python tools/ai-flavor-checker.py article.md --engine sanlian-writing
# 全库合规 / 断言 / 回归测试
python tools/lint_skill.py --all
python tools/run_prompts.py --all
python tools/tests/test_checker.py
