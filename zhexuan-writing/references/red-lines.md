# 红线与分寸（体制内写作特有）

浙江宣传能破圈，恰恰因为它在红线内做到了极致。红线不是枷锁，是让别人不敢碰的题你敢碰的底气。

## 能碰 / 不能碰 对照表

| 能碰 | 不能碰 |
|------|--------|
| 具体现象（一场婚礼、一个词、一家公司） | 制度根基、根本原则 |
| 群体标签背后的社会结构问题 | 为敏感群体「定性」定到全盘否定 |
| 国际对手的操作手法 | 动摇主权/宪法表述的立场 |
| 消费主义、市场乱象 | 把市场问题泛化为体制问题 |
| 代际价值观冲突 | 否定传统本身 |

## 六条铁律

1. **立场先行，但不喊口号**
   结论藏在推理里。检查方法：把文章里所有「必须」「坚决」「高度重视」删掉，论点还成立吗？不成立→论证不够，不是口号不够。

2. **批评对象必须具体**
   写「婚庆行业把婚礼做成标准化套餐」，不写「资本腐蚀一切」；写「精神贵族们」，不写「社会精英」。**具体才有靶心，泛化才会越界。**

3. **敏感话题必须有建设性出口**
   骂完必须给路：《小镇做题家》骂完嘲讽者，落到「共同享有人生出彩的机会」；《历史不会浓缩》情绪最烈处，写的是「怎么有利怎么干」。没有出口的批评 = 情绪，有出口的批评 = 政策建议。

4. **权威引用是锚，不是盾**
   领导人原话、典籍用来**立骨架**（一段的论点），不是用来堵嘴。检查：把引用删掉，这段还成立吗？成立→引用可有可无；不成立→引用成了论证替代品，重写。

5. **情绪可以被点燃，但不能烧穿**
   开头可以接住愤怒（「愤怒完全可以理解」），但文章 1/3 处必须出现理性转折。最烈处写最克制的话，是浙江宣传的招牌动作。

6. **给希望，不停留在抱怨**
   结尾必须升维：从事件→价值观→希望。读者合上文章时带走的是「路在脚下」，不是「世道不公」。

## 自检清单（发表前）

- [ ] 立场/观点是否明确到可以一句话概括？
- [ ] 批评对象是否具体（无泛化）？
- [ ] 是否给建设性出口？
- [ ] 权威引用是否在论证骨架位置而非堵嘴位置？
- [ ] 情绪段落是否在 1/3 处开始转理性？
- [ ] 结尾是否升维给希望？
- [ ] 有没有任何一句话会被断章取义成「反X」？有→改

## 为什么这样反而安全

体制内写作的翻车，几乎都死于「用力过猛」或「回避过度」。浙江宣传的方法论本质是：
- 用力过猛 → 用「具体靶心+建设性出口」对冲
- 回避过度 → 用「敢碰敏感题+立场先行」对冲

**它不靠少说话避险，靠把话说到位避险。**
