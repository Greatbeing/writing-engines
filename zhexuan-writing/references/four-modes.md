# 文体模式 = 原子操作的组合样本（认知引擎版）

> ⚠️ 本文件不是模板库，是「组合样本」：每种文体 = 特定原子操作的组合。
> 核心是 `atom-ops.md` 的 12 个原子。写作时：先选原子，再对照本文看同类文体怎么组合。
> 新文章 = 新原子组合，模式永远归纳不完——这就是本文件存在的理由。

# 九种文体模式：结构模板与范例拆解

九种模式对应浙江宣传的九类代表作。写作前先定模式，再套结构。

---

## 模式一：热点评议体

**适用**：网络热点、群体标签、争议事件（小镇做题家、对精日行为、品牌饭圈化）

**结构模板**：
```
标题：观点句（「嘲讽『小镇做题家』是一个危险信号」）
开头：事件钩（顶流明星考编+媒体神助攻 → 引爆网络）+ 定调一句
第一段：正名（概念从哪来、本意是什么、怎么被异化的）
第二段：制度/事实辩护（这个词攻击的机制，恰恰是合理的）
第三段：价值观升维（被嘲讽者才是生活的强者；真正不齿的是谁）
第四段：对策（政策层面 + 个体层面）
收尾：对仗金句（「出身并非结局，奋斗才是主题」）
```

**关键手法**：
- 先接住情绪，再修正认知：「愤怒完全可以理解」→ 然后才讲理
- 批评的具体对象要「指名道姓」（顶流明星考编事件、婚庆行业），不泛化
- 用「笔者以为」立观点，不用「众所周知」

---

## 模式二：重大时政体

**适用**：敏感时政、国际事件（佩洛西窜台、《历史不会浓缩于一个晚上》）

**结构模板**：
```
开头：事件 + 承接国民情绪（「愤怒完全可以理解」）
第一段：定调（红线不可触碰——先给立场）
第二段：史实（台湾问题来龙去脉，用史实压舱）
第三段：斗争逻辑（复盘对方操作 → 我们的棋局意识 → 过往行动证据）
第四段：定力收束（不意气用事；怎么有利怎么干；时与势在我）
收尾：金句（「历史不会浓缩于一个晚上」「历史终将见证」）
```

**关键手法**：
- **亮剑与克制并存**：态度坚决（谴责），但策略克制（不喊打喊杀）
- 用「敌进一尺、我还一丈」「拱卒」「以我为主」等棋局隐喻，把抽象斗争变成可感画面
- 史实段是压舱石——情绪上头时，史实让文章「稳」
- 结尾必须给「时与势在我」的希望，不能停在愤怒

---

## 模式三：纪念叙事体

**适用**：纪念日、成就回顾、人物纪念（长征两篇）

**结构模板**：
```
开头：事件钩（电视剧开播/90周年）+ 反直觉开场（开篇并不恢弘）
立骨：用 3-4 个「论断/问题」作脊柱（三句经典论断 / 四个时代问题）
每段：论断 → 数据锚 → 故事钩 → 权威佐证 → 当代对照
中段：古今双轨（历史事件 ↔ 当代实例交替）
结尾：升维到「每一代人」（把历史题变成当下的题）
收尾：金句（「这条路，不在历史书中，在每一个不肯认输的人脚下」）
```

**关键手法**：
- 反直觉开场制造张力：「对照剧名中的『伟大』，长征的开篇似乎算不上恢弘」
- 每段一个数据锚（300 米/人、8.6万→3万、600 余次战斗）+ 一个故事（半条被子、陈树湘）
- 权威论断（毛泽东三句话 / 总书记原话）是段落骨架，不是引用装饰
- 当代对照要具体（西昌航天团队平均 30 岁、乌兰察布绿色算力、第一书记）

---

## 模式四：危机舆论引导体

**适用**：重大舆情时刻、政策转段、民众情绪积压（《人民至上》不是《防疫至上》、《不对立不撕裂向前看向前行》）

**结构模板**：
```
开头：接住情绪（「随之而来的无奈、厌倦甚至愤怒，都是可以理解的」）
第一段：定调一句（「从来只有人民至上，没有所谓的防疫至上」）
第二段：数据压舱（用 4 组数据回答最尖锐的问题：为什么不放开）
第三段：大逻辑（以人为本、实事求是、因时制宜——我们的路怎么走来的）
第四段：承认问题（批评执行跑偏的三种形式，但不动摇政策根基）
第五段：对策 + 团结呼吁（软着陆、具体措施、船到湍流处更需心劲齐）
收尾：金句（比喻收束：大船 vs 游泳过河者）
```

**关键手法**：
- 这是最高难度的文体——**在情绪最烈的时刻，先承认情绪，再用数据把情绪转化为理解**
- 数据要「贴身」：不列抽象总数，列「每千人口床位」「每10万人ICU床位」「我国60岁以上未接种老人约5268万」这种可感知的对比
- 批评执行问题（层层加码/一刀切/跷跷板），明确「动辄归咎于政策本身也不符合实际」——批评具体执行者，保护政策根基
- 结尾必给希望：「船到湍流处，更需心劲齐」

## 模式五：清单批判体

**适用**：批评某种方法论的错误（《低级红高级黑的六种形式》、《新闻发布勿犯七个低级错误》）

**结构模板**：
```
开头：现象总述（舆论场经常冒头、杀伤力不小）
主体：按类型逐一拆解（六种形式/七个错误，每种给定义+案例+要害）
收尾：点透本质（不是罗列，是揭示共同病灶）
```

**关键手法**：
- **清单即武器**：把模糊的批评对象拆成可枚举的类型，读者可以对照自查——可转发、可保存、可传播
- 每种类型：一句话定义 + 真实案例 + 一句要害（「明褒实贬的软刀子」「上纲上线的扣帽子」）
- 批评的是「方法论错误」而非「某个人」——安全且锋利
- 网友反馈的关键：「敢讲实话，敢揭痛点」

## 模式六：乡愁共情体

**适用**：用一个小物件/小切口引发集体记忆（《霉干菜为什么叫博士菜》）

**结构模板**：
```
开头：物件（霉干菜）+ 反差悬念（为什么叫博士菜）
主体：物件背后的故事与奋斗记忆
转折：从个人记忆上升到群体现象（百名博士汇一市）
收尾：小菜不小，共鸣不小
```

**关键手法**：
- 小切口，大共鸣：一个物件承载一代人的共同记忆（「上学时发誓永不再吃的菜，现在却成了最爱」）
- 老话题（奋斗）用新容器（食物/乡愁）装——「面对拼搏奋斗这样的老话题，娓娓道来地讲述故事」
- 读者评论是最好的验收标准：眼角湿了 = 爆了

---

## 模式七：社会现象体

**适用**：生活方式、消费现象、社会议题（把婚礼还给自己、漂亮饭、哄哄自己）

**结构模板**：
```
开头：现象钩（宁波四无婚礼）+ 共鸣确认（「引发广泛共鸣」）
第一段：现象拆解（三种具体表现：套路化/繁琐/低俗婚闹）
第二段：归因（历史原因：熟人社会 → 今天结构变了；市场原因：服务者变规则制定者）
第三段：本质（婚礼的功能是见证，不是盛大——「重要的是见证，而非形式」）
第四段：给选择权（没有标准答案；但量力而行）
收尾：金句（「宾客如流水，你我二人此后同舟共济」「日子终归是自己过的」）
```

**关键手法**：
- 开头不评判，先共情：「只有社恐的人才知道这种婚礼有多轻松」
- 归因要有社会结构视角（熟人社会解体、城市化），不归咎个人
- 本质段用典籍/功能分析拔高（《礼记·昏义》）
- 结尾把选择权还给读者（「婚礼没有标准答案」）——不替读者做决定，读者才舒服

---

## 模式八：文化现象评议体

**适用**：文化热点、二创现象、流行亚文化（《嗑"圣黛"CP嗑的是什么》——AI 让林黛玉×孙悟空组 CP）

**结构模板**：
```
开头：现象钩（AI 视频让两个经典人物组 CP）+ 提问定调（到底嗑的是什么？）
第一段：现象溯源（走红历史、当事人回应、网友创作方式列举）
第二段：心理拆解（用「嗑的是什么」驱动，拆 2-3 层：反骨/补圆满/反差萌）
第三段：三句表态（多些理解/多些尊重/多些求新——每句一段）
收尾：金句（「只要对话继续，经典就永远不缺下一颗糖」）
```

**关键手法**：
- **用「是什么」驱动，不用「怎么看」**——「嗑圣黛CP嗑的是什么」比「如何看待圣黛CP」高级：先理解再表态
- 心理拆解要扎心：反骨（不吃压力的人）、补圆满（意难平→AI 推开重新来过的门）、反差萌（人设悬殊→莫名喜感）
- 收尾的**三句排比表态**（理解/尊重/求新）是浙江宣传的标志性结构——各占一段，先给包容再守边界再给方向
- 边界话术：「二创可以天马行空，却不能把原著仅仅当成流量素材；可以轻松娱乐，却不能丢掉对经典最基本的理解与尊重」——对仗式边界
- AI 视角天然加分：技术降低了创作门槛，是"文化活力"还是"边界风险"，正好构成文章的张力

## 模式九：重新定义体（观念正名体）

**适用**：代际话题、被误解的行为、价值观之争（《一代人有一代人的"大人感"》——为"长不大"的年轻人重写标准）

**结构模板**：
```
开头：三句「被评判」的引语（快三十了像孩子/没定性/不想结婚买房）
      → 共鸣（听得多了，自己也恍惚）
      → 反转定调（问题不在你身上，而是标准正在悄悄变化）
主体：N 段「长大，不是A，而是B」排比定义（每段：旧共识→为何失效→新定义→论证→金句）
结尾：升维到一代人 + 终极金句（「所谓大人，不过是那个终于把自己活明白了的人」）
```

**关键手法**：
- **反转定调是灵魂**：把「个人的问题」转译成「时代的命题」——「也许，问题并不在你身上」一句话把读者的委屈接住（招牌动作，类似《小镇做题家》的正名，但更温和：那边有对手要反击，这边没有对手，对手是「旧标准」这个抽象物）
- **「不是A，而是B」排比骨架**：五段全是同构对仗标题（不是完成任务，而是确认自我／不是掏空自己，而是先理顺自己／不是找到岸，而是学会在波动里站稳／不是硬扛不吭声，而是真实而不失控／不是高高在上，而是平视与尊重）——标题即论点，连读即宣言
- **每段内部节奏**：旧共识（曾经……）→ 现实变化（可今天……）→ 新定义（于是……）→ 论证 → 金句收束
- **保卫而不迎合**：不是夸年轻人「躺得好」，而是论证新标准其实要求更高（「权威可以靠身份获得，而尊重只能靠做人赢得」）
- 金句密度全类型最高，但全部长在论证的节点上，不悬浮

**何时选它**：当话题没有具体对手、只有「过时的共识」时——用重新定义代替批评，是浙江宣传写代际/观念题最温柔也最有力的打法。
