## 一、原子链（实际骨架）

| 位置 | 内容一句话 | 原子 |
|---|---|---|
| 开头 | 先摆前三季度 GDP、工业、服务业、外贸一串增速，再承认「部分人的体感有温差」 | 数据压舱 → 接情绪 |
| 第一节「经济层面」 | 房地产、股市、就业、新动能四条渠道，各配一组数字（如青年失业率 17.2%、毕业生 1270 万） | 拆机制 + 数据压舱×4 |
| 第一节末 | 20 年前想不到网约车；第一次工业革命后的新岗位 | 古今双轨 |
| 第二节「认知传导」 | 算法放大负面、圈层情绪传染；「三重过滤」 | 拆机制 + 升维 |
| 第三节「沟通层面」 | 批评统计发布只讲总量、回避具体关切 | 双层结构（开炮位） |
| 结尾 | 「体感温差」不是基本面不好的证据；对政府、对个体各提一层要求 | 反转定调 + 金句压缩 |

骨架画出来：

```
数据压舱 → 接情绪 → 拆机制×3（每层再嵌数据压舱）→ 古今双轨 → 双层结构 → 反转定调 → 金句压缩
```

## 二、对照组合规则

这条链最接近《人民至上》的「接情绪→反转定调→数据压舱×4→拆机制→双层→金句」，属于危机引导／热点评议体。差别在顺序：原文是**数据先行、情绪后接**，接情绪只有半句，读者的防御还没卸下，就先收到了一串增速。

换组合会更强：开头先放一个具体的人（例如一位求职中的应届生——原文里的「1270 万」正好可以落到一个人身上，即场景钩），再接情绪，再上数据，节奏就从「讲给你听」变成「陪你算账」。

## 三、红线体检

1. **靶心是否具体**：基本合格。第三节把炮口对准「统计发布的主要篇幅却放在总量增速和结构亮点上」这一具体做法，没有泛化为「有关部门」。第二节点名「平台算法的底层逻辑」，也落在具体机制上。
2. **保护层是否在场**：在场且偏厚。宏观政策、经济基本面、国际比较三层都立住了；「外部不确定性」「实属不易」一段篇幅较长，保护层略压过了开炮位。
3. **出口是否充分**：有两个出口——对个体是「有意识地跳出茧房」，对政府部门是让统计解读「更接地气」。前者可执行，后者偏原则。
4. **意象统一**：「温差」贯穿全文，「传导链」「三重过滤」都服务于它，没有混用，这是本文做得最好的一项。
5. **金句数量**：约 3 处，在上限内。最强的一句长在第三节论证节点上：「直面问题不会制造悲观，回避才会让猜测和情绪去填补空白」。
6. **说教度**：结尾一段出现「在笔者看来」，且用「不妨多一份长远眼光」，语态平视，未出现「你们应该」。

## 四、结论

**一句话总评**：拆机制精度高、数据压舱扎实，是一篇站得住的热点评议；短板是接情绪太晚、太短，结尾收在劝说上而不是结构化表态上。

**最值得改的 2 处**：

1. **开头调序**：把「部分人的体感有温差」提到第一句，后面接一个具体求职者或小企业主的场景钩，再放 GDP 数据。数据压舱应放在质疑最烈处（「凭什么说经济不错」），而不是放在读者还没开口之前。
2. **结尾改成三句表态**：现在的收尾是两段建议加一句「在笔者看来」。可压成一组三句排比——对政府、对平台、对个人各一句——原文已有的那句「为的不是强求所有人感受一致」可以留作第三句的底座。
