# 第十八讲 稿：写完放一夜再改

十七讲下来，你手里有十七个动作。最后一讲不教新动作，教怎么把它们用在自己的稿子上。

刚写完的稿子，你看它全是好的，因为你记得自己想说什么，脑子会自动补上没写出来的东西。读者没有你的脑子。

## 一、这一讲你要学会的一个动作

> **写完放一夜。第二天把自己当成陌生人，从头念一遍，按一张清单改。**

判断标准：**第二天念的时候，你在哪里卡住、哪里想跳过，那里就是要改的地方。**

## 二、名家怎么改

很多作家都有「冷处理」的习惯：写完锁进抽屉，过一阵再拿出来改。作家改稿的具体说法，各家记载不一，这里只取这个做法，不引原话。

**写的时候你是作者，改的时候你要做读者。** 中间那一夜，就是用来换身份的。

## 三、AI 写成什么样

机器写完不会回头，也不会觉得哪里别扭。它的第一稿就是最后一稿，所以你总能在里面找到前十七讲说过的每一种毛病。

拿 AI 的稿子练改稿，反而是个好办法：**毛病多，改起来手熟。**

## 四、改一遍：一张清单

第二天念稿，按顺序过一遍，每一条对应一讲：

| 查 | 对应 |
|---|---|
| 第一句是不是道理？ | 第一讲 起 |
| 有没有写满形容词、没有动作？ | 第二讲 行、第八讲 人 |
| 结尾有没有升华？最深情的那句能不能删？ | 第三讲 收、第十五讲 白 |
| 删掉三成字，意思还在不在？ | 第四讲 改 |
| 人物是不是在说你的话？ | 第五讲 话 |
| 读者最想知道的在不在第一段？ | 第九讲 序 |
| 道理后面有没有事？ | 第十讲 理 |
| 声音有没有中途换人？ | 第十一讲 调 |
| 有没有钻进两个人的脑子？ | 第十三讲 视 |
| 是不是转了不止一次？ | 第十六讲 转 |
| 最重要的那句概括，拆成戏了没有？ | 第十七讲 场 |
| 标题能不能换到别人的文章上？ | 第十二讲 题 |

## 五、你的练习

挑这十八讲里你最满意的一篇练习，放一夜。第二天：

1. 大声念一遍，在卡住的地方画线。
2. 按清单逐条查，每条最多改一处。
3. 把改前和改后放在一起，写三句话：改了什么，为什么改，哪一条你最常犯。

最后那一条，就是你接下来一年要盯着改的毛病。**风格的另一半，就是你知道自己的毛病在哪。**
