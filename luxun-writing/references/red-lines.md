# 红线与常见翻车

## 红线（命中即重写）

1. **民国腔**：堆砌“的罢”“底”“倘若……便”“我们中国人”等旧腔（引用原文除外）。
2. **冒充鲁迅**：用鲁迅口吻写，或编造“鲁迅说过”的话。网上大量伪鲁迅语录，拿不准就不引。
3. **点名攻击**：讽刺对象指向可识别的真实个人，或包含未经证实的指控。
4. **群体歧视**：把批评扩大到地域、民族、性别等群体。批评的是心态和机制。
5. **鸡汤结尾**：“让我们”“相信未来会更好”“愿每个人”。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 只骂不剖 | 情绪很满，说不清机制 | 写出“揭底一句”，说清它为什么会这样 |
| 遍地开花 | 一篇批了五件事 | 只留一个靶子 |
| 阴阳怪气 | 反语太浅太密 | 反语只用在一两处关键地方 |
| 金句成灾 | 每段一句狠话 | 揭底句最多两句 |
| 居高临下 | 通篇“他们”，没有“我” | 加一处自剖 |
| 民国 cosplay | “然而”满篇、“罢”字结尾 | 换成今天的说法 |
