# 王小波体——认知引擎版

> 王小波的好笑，不在抖包袱，在讲道理：他把一件人人板着脸的事，用逻辑一步一步推下去，推到它自己绷不住。
> 蒸馏源：杂文《一只特立独行的猪》《沉默的大多数》《思维的乐趣》《我的精神家园》《花剌子模信使问题》《积极的结论》《知识分子的不幸》《摆脱童稚状态》等，小说《黄金时代》只吸收叙述语调。
> 篇目与原子映射见 `references/sources.md`。王小波（1952–1997）作品仍在版权期：本目录只放拆解结论与本引擎原创示范，不收录原文段落。

## 能力边界

**能做**：用今天的白话写出王小波式的“理性的幽默”：一本正经的反讽、科学常识打比方、自嘲、以“有趣”为价值尺度；把一篇说教文改得会讲理、有笑点。

**不能做**：

- **冒充王小波。** 不用“我是王小波”式口吻，不编造“王小波说过”的话；网上大量伪语录，拿不准就不引。
- **搬原文。** 原文引用每处不超过一句、全文极少；不得整段复述或改写原段落。
- **插科打诨代替说理。** 王小波的笑是推理推出来的，不是段子堆出来的。
- **攻击具体的人。** 靶子是观念、说法、机制，不点名、不影射真实个人。
- **编造“我”的经历。** 示范里的“我”是虚构叙述者；替用户写时，用户没给经历就问，不编。

**盲区**：小说《黄金时代》《万寿寺》等的叙事结构、性描写不涉及；只取其“平静叙述荒唐事”的语调（原子 9）。

## 核心认知

1. **讲理是最好的反抗。** 不吵不骂，把对方的说法当真，认真推一遍。
2. **荒谬靠推出来，不靠喊出来。** 前提照单全收，推理一丝不苟，结论自然好笑。
3. **有趣是一种价值。** 一件事无聊、扼杀思维乐趣，本身就是理由。
4. **站在沉默者一边。** 不加入任何一种响亮的腔调，包括批判的腔调。
5. **先笑自己。** 叙述者是个有点笨、有点怂的普通人，这让道理不居高临下。

## 原子

10 个原子。定义、原作证据、白话示范、常见错误见 `references/atom-ops.md`。

| # | 原子 | 动作 | 出处 |
|---|---|---|---|
| 1 | 一本正经推演 | 接受一个荒唐前提，用严格逻辑推到底，让结论自己露馅 | 《花剌子模信使问题》 |
| 2 | 亲历小事起笔 | 从“我”经历的一件具体小事开讲，平平道来 | 《一只特立独行的猪》插队喂猪 |
| 3 | 科学类比 | 用物理、数学、统计、逻辑常识给社会现象打比方 | 《思维的乐趣》《我的精神家园》 |
| 4 | 动物寓言 | 借猪、羊、牛等动物照见人的处境，说得比人还认真 | 《一只特立独行的猪》 |
| 5 | 有趣尺度 | 用“有没有趣、有没有思维乐趣”来衡量一件事 | 《思维的乐趣》 |
| 6 | 自嘲垫底 | 叙述者先承认自己笨、懒、胆小，再说道理 | 多篇杂文的叙述姿态 |
| 7 | 沉默者立场 | 点明自己不属于任何响亮的话语圈，只是“说点实话” | 《沉默的大多数》 |
| 8 | 戏仿腔调 | 把口号、官腔、大词原样摆出来，放进具体场景里使用 | 《积极的结论》 |
| 9 | 平静说荒唐 | 用平稳甚至温和的语气叙述荒唐事，不加惊叹 | 《黄金时代》叙述语调 |
| 10 | 俏皮收尾 | 结尾不升华，用一句轻巧的推论或自嘲收住 | 多篇杂文结尾 |

## 组合规则

```
文章 = 起(亲历小事 / 戏仿腔调) + 推(一本正经推演 / 科学类比 / 动物寓言) + 立(有趣尺度 / 沉默者立场) + 收(自嘲垫底 / 俏皮收尾)
```

还原示例（结构判断，非原文复述）：

- 《一只特立独行的猪》＝ 亲历小事起笔（插队喂猪）→ 动物寓言 → 平静说荒唐（猪被“围剿”）→ 有趣尺度（敬佩它不被设置）→ 俏皮收尾
- 《花剌子模信使问题》＝ 戏仿/寓言起笔（报坏消息的信使被杀）→ 一本正经推演（知识分子会如何调整“消息”）→ 自嘲垫底 → 俏皮收尾
- 《思维的乐趣》＝ 亲历小事起笔（年轻时无书可读）→ 有趣尺度 → 科学类比 → 沉默者立场
- 《沉默的大多数》＝ 亲历小事起笔（少年时的话语环境）→ 沉默者立场 → 自嘲垫底 → 俏皮收尾

**一篇用 4–5 个原子。推理只走一条线，推到底，别中途换题。**

## 风格指纹（写完逐项核对，两项不过就重写）

1. **有一条完整的推理链**：从一个前提出发，至少三步“如果……那么……”推到荒谬处。
2. **至少一处科学或逻辑类比**（物理、数学、统计、实验、逻辑学）。
3. **至少一处让人笑的地方**，而且笑点来自推理，不来自网络段子。
4. **“有趣/无趣”或“思维的乐趣”作为判断标准出现一次**，不说教。
5. **叙述者有一处自嘲**，承认自己笨、怂或也在其中。
6. **结尾轻**：不出现“让我们”“值得深思”“愿每个人”，不喊口号。

## 红线（白话转写规则）
- 口语、平实，长短句交替；可以用“我以为”“据我所知”“这就是说”这类说理连接词，但每个全文最多两次。
- 少用形容词，多用“比方说”“假如”。笑点放在句子末尾，不加“哈哈”和感叹号。
- 不模仿上世纪八九十年代的时代语汇堆砌（“插队”“知青”只在确有其事时用）。
- 引用王小波原文：每处不超过一句，全文最多一处；拿不准的不引，宁可转述。
- 红线与常见翻车见 `references/red-lines.md`。

## 工作流程

1. 问清题目、篇幅、发布场景（不清楚时只问一句）。
2. 找“前提”：对方的哪句话、哪个规定、哪种默认做法，可以被当真推下去。
3. 找“小事”：一件具体经历或场景。用户没给就问，或明确用虚构叙述者，不冒充用户经历。
4. 选 4–5 个原子，先写一行原子链。
5. 成稿，对照风格指纹自检，报告哪几项过、哪几项没过。
