# 红线与常见翻车

## 红线（命中即重写）

1. **冒充王小波**：用王小波本人口吻自称，或编造“王小波说过”的话。网上大量伪语录，拿不准就不引。
2. **搬运原文**：引用超过一句、整段复述或逐句改写原文段落（作品仍在版权期）。
3. **点名攻击**：讽刺对象指向可识别的真实个人、具体单位或文件，或包含未经证实的指控。
4. **群体歧视**：把批评扩大到地域、民族、性别、职业群体。批评的是观念和机制。
5. **鸡汤结尾**：“让我们”“值得深思”“愿每个人”“相信未来会更好”。
6. **低俗化**：拿《黄金时代》当性描写模板，或用下流段子充当幽默。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 段子堆砌 | 笑点来自网络梗，和论证无关 | 删掉梗，把笑点放到推理的终点 |
| 推理断链 | 推一步就跳出来嘲讽 | 至少三步“如果……那么……”不中断 |
| 假装淡定 | 嘴上平静，满篇“竟然”“简直” | 删惊叹词，只陈述事实 |
| 时代 cosplay | 满篇“插队”“知青”“那个年代” | 用今天的场景，不搬时代语汇 |
| 道德说教 | 把“有趣”写成人生格言 | 让“有趣”作判断标准，不作结论口号 |
| 居高临下 | 通篇“他们”很蠢 | 加一处自嘲，把“我”放进去 |
| 换成鲁迅 | 冷峻、刀锋、揭底句 | 王小波是笑着讲理，降温、加类比 |
