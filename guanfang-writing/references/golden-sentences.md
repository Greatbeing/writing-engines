# 金句句式模板库

浙江宣传的金句密度是它「可截图传播」的关键。以下句式直接套用。

## 一、对仗收尾（段落/全文收口）

```
格式：A 不是 B，C 才是 D
- 出身并非结局，奋斗才是主题
- 脚印就是方向，信念就是罗盘
- 婚礼是一天的见证，而婚姻才是一生的同舟

格式：X 不在 A，在 B
- 这条路，不在历史书中，在每一个不肯认输的人脚下

格式：A 者难 B，C 者易 D
- 孤举者难起，众行者易趋
```

## 二、反问激活（开头/转折处制造张力）

```
- 不禁要问：长征，何以永远？
- 为什么要办婚礼，究竟是办给谁的，该如何办？
- 谁说「做题」就一定选拔不出来优秀的人才？
```

## 三、细节并列（用清单代替形容词）

```
- 接亲游戏、豪车车队、灯光舞台、司仪煽情、跟妆跟拍，每一项明码标价
- 翻越冰山雪岭，穿越沼泽草地，纵横十余省，长驱二万五千里
```

## 四、数字锚（让抽象变具体）

```
- 平均每前进 300 米就有一名战士倒下
- 中央红军从 8.6 万余人锐减至 3 万余人
- 宾客 6 点 30 分陆续到场，9 点 22 分才终于吃上饭
- 300 多万名第一书记和驻村干部扎根乡土，9899 万农村贫困人口全部脱贫
```

## 五、网友评论入文（真实感+传播钩）

```
- 「只有社恐的人才知道这种婚礼有多轻松」
- 「感觉和流水线没有什么区别，除了对象不一样，剩下的都一样」
- 「宾客如流水，你我二人此后同舟共济」
```

## 六、名句化用（借经典的力量）

```
- 世界以痛吻我，报之以歌（泰戈尔）
- 一个行动胜过一打纲领（马克思）
- 孤举者难起，众行者易趋（典出古语）
```

## 七、隐喻系统（给抽象斗争一个画面）

```
- 棋局：棋子/棋局/拱卒/以我为主
- 长征：雪山草地/大渡河/娄山关/腊子口/火种/红飘带
- 考试：打怪升级/鲤鱼跃龙门
```

## 使用规则

1. 每篇文章至少 3 处金句，但**金句密度过载会显得油**——议论段之间的「呼吸感」比金句更重要
2. 对仗句只能用于收尾/转折，不能用于开头（开头要具体事件，不要格言）
3. 网友评论必须真实（来自评论区/报道），不得编造
4. 金句要能脱离上下文被单独转发——写完检查：这句话单独发朋友圈成立吗？
