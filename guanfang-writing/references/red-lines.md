# 红线与常见翻车

## 红线（命中即重写）

1. **不编造领导人讲话与政策文件。** 不虚构、不拼接、不“合理推测”任何领导人原话、会议精神、文件内容。用户未提供且无法公开查证的，一律不写，或标【待核：××原文】。
2. **不编造数据与文号。** 统计数据、文件文号、发布日期、会议届次必须有可靠出处；没有就写【待核】，不凭印象写近似数。
3. **政治表述以官方权威提法为准。** 机构名称、规范简称、重大论断、理论表述照官方正式文本使用，不自创提法，不改写、缩写或“意译”既定表述；拿不准的提法交人工核对。
4. **不冒用署名。** 不以“人民日报评论员”“任仲平”“宣言”等名义署名，产出只作仿写习作或草稿。
5. **不编造新闻事实。** 示例人物与事件若为虚构，须在文末注明；不把虚构人物写成真实姓名、真实单位。
6. **版权。** 不整段搬运报刊原文；引用每处不超过一句且全文极少，拿不准不引。
7. **不越界定性。** 不对敏感事件、群体、国际关系作超出公开权威表述的定性。

## 常见翻车

| 翻车 | 表现 | 改法 |
|---|---|---|
| 空调高唱 | 通篇“意义重大”“影响深远”，没有人和数 | 每个判断后三句内落到具体的人、地、数 |
| 口号堆叠 | 排比、四字格连成串，读着响、想不起 | 排比要递进；一段四字格不超过三组 |
| 新媒体腔 | “家人们”“破防”“绝绝子”、截图金句 | 换回庄重书面语；需要爆款请用 zhexuan-writing |
| 只唱赞歌 | 没有一处承认困难 | 后三分之一加辩证回应 |
| 训话口吻 | “你们要”“必须认识到” | 改用“我们”，把要求写成共同的选择 |
| 史实硬凑 | 年代、出处记不准就用 | 拿不准不写，或换成确定的史实 |
| 假数据 | “据统计”后面跟一个无出处的整数 | 标【待核】，交人工补出处 |
