# 拆解：《被替代的不是人，是站在原地的那一步》

> 用法②：拆解流程。题目要求「把文章贴进来」但未附原文，本稿以本目录已有示例 `2026-11-25-AI焦虑时评.md` 作为被拆文本。只拆解，不代写新文。

## 一、原子链（实际骨架）

| 段落 | 内容一句话 | 原子 |
|---|---|---|
| 第1段 | 「AI会不会抢走我的工作」是心里的一根刺，这种焦虑不丢人 | 接情绪 |
| 第2段 | 换个问法：抢走的是工作，还是工作里的某种做法 | 反转定调 |
| 一节「十二个人，留下四个」 | 原画师团队从12人变4人，「被会用AI的同事取代」 | 场景钩 + 数据压舱 |
| 二节「机器不会告诉你」 | 主管把4个工人调去质检 | 场景钩 + 重新定义（岗位没消失，只是挪了位置） |
| 三节「慢一点」 | 职校老师教学生被替代得慢一点 | 场景钩 + 金句压缩 |
| 四节「焦虑要接住」 | 批评企业只算账不算人；职业教育与社保兜底 | 双层结构 |
| 结尾 | 三行排比：焦虑可以有／工具在变／被替代不可怕 | 三句表态 |

骨架画出来：

```
接情绪 → 反转定调 → 场景钩×3（含数据压舱）→ 重新定义 → 双层结构 → 三句表态
```

## 二、对照组合规则

这条链对应「社会现象体／热点评议体」：开头接情绪、中段用三个样本拆开「替代」这个概念、结尾结构化表态，和《大人感》「接情绪→反转定调→重新定义×N→金句」同一路数。

可以更强的地方：数据压舱只有「12人变4人」「工资降三成」两个个体数字，缺一个**贴身化的宏观数字**放在质疑最烈处（例如「多少岗位受影响」），焦虑的人最想问的那句没有被数字正面回答。

## 三、红线体检

1. **靶心是否具体**：基本合格。批评落在「降本增效不算人」的企业经营者、「裁员前有没有转岗培训」这个环节上，没有泛化成「资本」「技术」。
2. **保护层是否在场**：在场。「职业教育要跟上，社会保障要兜底」立住了抽象原则；「AI不是洪水猛兽」也保护了技术本身。
3. **出口是否充分**：偏弱。结尾三句给了态度，但没有一个可执行的小行动，读者看完知道「别站在原地」，不知道第一步迈哪儿。
4. **意象统一**：有一处混用——前文是「刺」，后文出现「镜子」「洪水猛兽」「万能钥匙」，三个比喻挤在两句里。
5. **金句数量**：约3处（「替代发生在人和人之间」「岗位挪了位置」「被替代不可怕」），在上限边缘，未超。

## 四、结论

**一句话总评**：接情绪和双层结构走得稳，骨架完整，属于合格的热点评议；短板在数据压舱太个体、出口太虚。

**最值得改的2处**：

1. 在第2段反转定调之后补1个贴身化宏观数字（来源须可查证【待核】），让「问题换了问法」有压舱物。
2. 删掉第四节「洪水猛兽／万能钥匙／镜子」三连比喻中的两个，只留「镜子」，并在三句表态前加1句可执行出口（如「从这个月学会一个新工具开始」）。
